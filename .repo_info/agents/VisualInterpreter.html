VisualInterpreter.py — 视觉解释 Agent

文件路径: src/AstroAgent/agents/multi_agents/VisualInterpreter.py

角色: LangGraph workflow 的第一个 agent 节点。负责从输入图像/FITS 中提取光谱数据、检测特征、执行暴力线匹配。

调用关系: 编排 utils/VI.py 的数值算法 + 调用 VLM/LLM 做视觉判断和坐标映射

Agent 1 of 5 FITS + PNG dual channel stream support NPZ output

3. FITS 通道 (line 52)

load_spectrum_from_fits(state)

State 赋值位置: agent 层唯一赋值点。从 utils/VI.py 获取纯 dict 后写入 state。

_runtime.configs.params → arm_name, arm_wavelength_range │ ▼ _load_spectrum_from_fits(state['file_path'], arm_names, arm_wavelength_ranges) │ ▼ spectrum_dict {wavelength, flux, snr, ivar} │ state['spectrum'] = spectrum_dict ← agent 层赋值

FITS 通道跳过 PNG 通道的 Phase A–C（坐标轴检测、裁剪、光谱重建），因为 FITS 数据本身已经是标定好的物理量。

从 state['spectrum'] 取出 wavelength, flux, ivar/snr，构建吸收线和发射线检测参数字典（全部来自 .env 配置，不硬编码），调用 run_iterative_feature_detection()。

参数来源

  • delta_chi2_base, dynamic_threshold_factor, global_delta_chi2_threshold

发射线参数 (em_*)

6. Phase E: Continuum 拟合 (line 319–329, in run())

调用 run_continuum_fitting_masked(wavelength, flux, peaks=emission_records, troughs=absorption_records, chebyshev_degree, ...)。特征区域（中心 ±3σ）被 mask 掉后再拟合 Chebyshev 连续谱。Chebyshev 阶数可手动指定（chebyshev_degree）或自动选择（chebyshev_min_degree – chebyshev_max_degree）。

拟合结果写入 state['continuum'] 和 state['residual_spectrum']。

7. brute_force_line_matching (line 332–335, in run())

统一单次调用（旧三模式 qso/elg/lrg_bgs 已 deprecated）：

9. 设计原则

State 赋值在 agent 层

utils/ 下的所有函数返回纯数据（dict/array/list），不接收 state 也不修改 state。所有 state['...'] = ... 赋值在 VisualInterpreter agent 层完成。这使得 utils 函数可独立测试和复用。

双通道统一接口

FITS 和 PNG 通道产出的 spectrum_dict 具有相同的 key schema（wavelength, flux, snr, ivar），Phase D–E 的后处理管线对两个通道完全透明。

参数外部化

所有算法参数（特征检测阈值、容差、Chebyshev 阶数等）从 .env 经由 ParamsConfig 注入，不在代码中硬编码。

流式输出

LLM/VLM 调用通过 BaseAgent._stream_invoke() 支持流式输出（.env 中 STREAM=true）。want_tools=True 的 agent 路径保持 ainvoke()。
