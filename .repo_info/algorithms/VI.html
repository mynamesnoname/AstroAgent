1. OCR / 坐标轴刻度检测

1.1 Tesseract (_detect_axis_ticks_tesseract, line 25)

对图像做 Gaussian 模糊 + 自适应阈值二值化，用 Tesseract 逐字识别数字。过滤出可转为 float 的文本，输出 (value, pixel_position, bbox_scale) 三元组。

Tesseract 在光谱图上的数字识别效果较差。代码注释中标注 "Tesseract is not good. I prefer paddle."

1.2 PaddleOCR (_detect_axis_ticks_paddle, line 63)

使用 PaddleOCR 直接对整个图像做文字检测+识别（关闭文档方向分类和去翘曲），输出所有识别文本的中心坐标和包围盒尺寸。结果同时保存为图像和 JSON。

2. 边框检测与图像裁剪

2.1 _detect_chart_border (line 96)

二值化 → 形态学闭运算去噪 → 找最大轮廓 → 按 margin 微调（默认 top=10/right=10/bottom=10/left=10）。返回 {x, y, w, h}。

2.2 _crop_img (line 146)

按 border_info 裁剪图像并保存。简单的 numpy slicing: img[y:y+h, x:x+w]。

2.3 迭代裁剪 (VisualInterpreter.border_detection_and_cropping)

裁剪后用 VLM 检查四边是否干净（无残留坐标轴/刻度/文字），不干净则增加对应边 margin（每次 +2px），直到四边都通过或 margin 达到上限 30px。

3. 像素坐标重映射与拟合

3.1 _remap_to_cropped_canvas (line 178)

将原图坐标系中的刻度位置映射到裁剪后的画布坐标: (ox - x0, oy - y0)，超出画布范围的 clamp 到边界。同时兼容 None 坐标。

3.2 _pixel_tickvalue_fitting (line 209)

对 x/y 轴分别做 加权线性拟合 (scipy curve_fit): value = a × pixel + b。权重 = sigma_pixel / sqrt(conf_llm)。输入至少 2 个点，输出 a, b, rms, residuals。

4. 曲线提取与光谱重建

4.1 _process_and_extract_curve_points (line 265)

读取裁剪后的图像 → 转灰度 → 阈值 200 二值化 (THRESH_BINARY_INV)，白色区域的像素点即为光谱曲线点云。返回 (x, y) 坐标列表和灰度值列表。

4.2 _convert_to_spectrum (line 325)

像素点云 (x, y) │ ├── a_y × y + b_y → flux ├── a_x × x + b_x → wavelength │ ├── [optional] 波段重叠区域去除 (find_overlap_regions) │ └── 删掉落在重叠区的点 │ └── average_flux_by_wavelength() : 同波长取均值 │ └── 统计量: max/min unresolved flux, std, SNR, delta_flux

SNR 估计: SNR = mean_flux / std_flux (对每个波长)。取中位数 snr_medium 作为整体信噪比指标。

5. FITS 光谱加载 (_load_spectrum_from_fits, line 426)

支持两种 FITS 格式：

格式结构示例
多波段分波段每个波段独立的 WAVELENGTH/FLUX/IVAR/SNR/MASK HDUDESI (B,R,Z), CSST (U,V,I)
单表格单个 BinTableHDU 包含 WAVELENGTH/FLUX 列常见光谱 catalog

多波段格式的处理流程：读取各波段 → 质量 mask (specmask==0 & ivar>0) → 去除波段重叠区 → 按波长排序去重（同波长取均值）→ 高斯平滑 (σ=2)。

波段名称和波长范围从 .env 中的 ARM_NAME / ARM_WAVELENGTH_RANGE 读取，未配置则报错。

6. Continuum 拟合

6.1 run_continuum_fitting (line 870)

用 specutils 的 Chebyshev1D 多项式拟合连续谱。阶数可手动指定或自动选择。计算 residual_flux = flux - continuum。还额外计算对数导数 dlnF/dλ，根据导数符号划分单调区间，生成自然语言描述。

6.2 run_continuum_fitting_masked (line 1028)

先用已检测到的峰/谷区域（中心 ±3σ，σ = FWHM_A / 2.355）mask 掉特征区域，然后在剩余"干净"光谱上拟合 continuum。可用点数 < 20 时回退为全谱拟合。拟合后在完整波长数组上插值评估。

6.3 generate_continuum_description (line 951)

根据 monotonic regions 生成自然语言描述，例如：
"The continuum has a value of 2.027 at 4000.0 Å, monotonically increases from 4000.0 Å to 5010.1 Å, reaching 3.499 at 5010.1 Å; ..."

7. 迭代特征检测 (入口)

run_iterative_feature_detection (line 1192)

先找吸收谷，再找发射峰。吸收线更窄更深，率先 mask 掉可避免宽发射线干扰。详细算法见独立页面。

吸收线检测参数 (absorb)

  • 窗口: window_width, window_overlap
  • Δχ²: delta_chi2_base, dynamic_threshold_factor, global_delta_chi2_threshold
  • FWHM: fwhm_min, fwhm_max
  • SNR 深度: snr_depth_threshold
  • Smoothed: smooth_sigma_trough, smooth_prominence_frac_trough

发射线检测参数 (emission)

  • 窗口: window_width, window_overlap
  • Δχ²: delta_chi2_base, dynamic_threshold_factor, global_delta_chi2_threshold
  • FWHM: fwhm_min, fwhm_max
  • 系统误差: sys_err_frac (第二遍回退)
  • Smoothed: smooth_sigma, smooth_prominence_frac

8. 暴力线匹配 (brute_force_line_matching, line 1688)

目的: 对已检测到的峰/谷做物理谱线标注，生成红移假设供 LLM 做定量分析

静止系谱线表: 19 条发射线 (Lyα ~ S[II]b) + 15 条吸收线 (Ca K/H ~ Hα_abs)

8.1 三相流程

Phase 1: 逐峰逐线锚定

对每个峰（或 lrg_bgs 模式下的每个谷），假设它是某条静止系谱线，计算红移 z = λ_obs / λ_rest − 1。

用 z 预测所有其他谱线的观测位置，在容差内匹配峰/谷。每条匹配记录为 (obs_wl, line_name, z) 三元组。

Phase 2: Union-Find 去重

节点 = (wavelength, line_name) 对。同一假设内所有节点互联。每个连通分量 = 一个独立的物理场景。

Phase 3: 格式化输出

按 N_emission + N_absorption 降序排列。有效独立约束数 < 2 的假设被丢弃。

8.2 三模式

Mode锚定峰锚定线表容差缺失线报告
qso全部峰全部 19 条发射线（含 BLR 宽线）100Å缺失发射线
elg仅窄峰全部 19 条发射线30Å缺失发射线
lrg_bgs窄峰 + 谷锚定非 broad 发射线 (13条) + 吸收线30Å缺失吸收线
lrg_bgs 谷锚定: LRG/BGS 以吸收线为主要特征，因此额外遍历每个谷作为吸收线锚点，计算红移后验证其余谷和窄峰是否吻合。

8.3 每条假设的输出字段

字段说明
Hypothesis锚定对字符串，如 "3788.0-Lyα, 4840.0-C IV"
z_max / z_min / z_spread组内所有匹配对的红移统计
Emission / Absorption matches格式化匹配列表 (含 Amp, FWHM, width_class, ⚠ width mismatch)
N_emission / N_absorptionmin(独立波长数, 独立线名数)——保守估计有效独立约束数
Redshift warningz too low for QSO/Galaxy (低于 min_redshift 阈值)
Missing lines观测范围内未被匹配的关键谱线及预测位置
Observable lines所有在观测范围内的谱线及其匹配状态 (matched / NOT matched)
Dn4000分别用 z_max 和 z_min 计算的 4000Å Break 指标、strength、三段斜率

8.4 关键细节

D_n(4000) 4000Å Break

观测系→静止系转换后计算 Dn4000 = mean_flux(4000-4100) / mean_flux(3850-3950)。<1.3 weak / 1.3-1.5 moderate / >1.5 strong。同时输出三段线性斜率用于区分星族年龄。

宽度不匹配警告

宽线 (Lyα, C IV, C III], Mg II) 配窄峰 或 窄线 ([O III], [N II] 等) 配宽峰 → ⚠ width mismatch。"both" 类 (Balmer系) 跳过此校验。

发射线/吸收线宽窄分类

Broad (BLR 宽线区)

  • Lyα (1216.0)
  • C IV (1549.0)
  • C III] (1909.0)
  • Mg II (2800.0)

Both (BLR+NLR)

  • He II (1640.4)
  • Hε, Hδ, Hγ, Hβ, Hα (Balmer)

Narrow (NLR 窄线区)

  • Ne [V] (3426.0)
  • O [II] (3727.0)
  • O [III]a/b (4960/5008)
  • N [II]a/b (6550/6585)
  • S [II]a/b (6718/6733)

N_emission / N_absorption 的保守计数

取 min(独立波长数, 独立线名数)。防止"一峰配多线"（波长少于线名）和"一线配多峰"（线名少于波长）两种虚高情况。
