An LLM-powered multi-agent system that reads astronomical spectra the way a human astronomer does. From a spectral image (PNG or FITS), it digitizes the trace, detects emission and absorption features, generates redshift hypotheses through brute-force line matching, evaluates each hypothesis with independent LLM agents, cross-verifies them through adversarial review, and delivers a structured final report with calibrated confidence.

Scientific targets: source classification (QSO / GALAXY) and redshift measurement for DESI and CSST survey spectra.

Python 3.12 LangGraph LangChain MCP Qwen3-max OpenCV PaddleOCR PyWavelets CWT

Pipeline

Stage 1 VisualInterpreter

FITS channel.

  • Loads multi-band spectral data from FITS files.
  • Runs CWT wavelet feature detection to find emission peaks and absorption troughs.
  • Fits a Chebyshev continuum.
  • Uses redrock to generate redshift hypotheses.

PNG channel — to be documented.

HypothesisAnalyst
Step 2a Single-Hypothesis Evaluation
  • Each redshift hypothesis gets an independent LLM agent.
  • Each agent searches features around its predicted lines, queries the knowledge base via grep_kb, and produces a per-hypothesis confidence report.
Step 2b Hypothesis Synthesis
  • Compares all per-hypothesis reports side by side, building contradiction matrix across hypotheses.
  • LLM reads raw spectrum regions to resolve conflicts.
  • Delivers a structured verdict with the best hypothesis and supporting evidence.
AnalysisAuditor
Step 3a Feature Auditor
  • Build feature contradiction matrix across hypotheses.
  • Read spectrum at each claimed wavelength; judge real vs. noise.
  • Check [O II] and Lyα forest morphology.
  • Verify doublet ratios and orphan components.
  • Identify emission–absorption composite profiles.
Step 3b Result Auditor
  • Independent adversarial second review of the synthesis verdict.
  • Auditor LLM re-examines the evidence without access to the original synthesis reasoning.
  • Outputs a calibrated confidence: CONFIRM, DOWNGRADE, REJECT, or UNCERTAIN.
Stage 4 ReportWriter
  • Generates a structured report with six sections: source classification, redshift estimate, confidence assessment, spectral line evidence, uncertainty analysis, and recommendations.
  • Produces both a human-readable Markdown document and a structured JSON summary (in_brief) for downstream cataloguing and batch analysis.
Stage 5 · optional SelfEvolve
  • Optional self-improvement loop, triggered when ground truth is available (from FITS metadata or environment variables).
  • Compares the synthesis verdict against ground truth; if they disagree, runs a two-round LLM analysis.
  • First round: blind review of the discrepancy without revealing which answer is correct. Second round: root-cause identification that pinpoints what went wrong.
  • Structured failure records are saved for batch analysis to identify systematic weaknesses across many spectra.

Feature Detection

CWT + Δχ² + global refinement

Peak and trough detection are fully symmetric. The pipeline:

1. Chebyshev continuum fit (mask features → fit → iterate)

2. CWT (Mexican Hat, scales 1–80) + smoothed residual dual-path candidate generation

3. Sliding-window Δχ² iterative joint fitting → cross-window deduplication

4. Global multi-Gaussian refinement with iterative outlier rejection

Troughs (absorption) are found first, then peaks (emission) — preventing wide emission lines from swallowing narrow absorption troughs. A two-pass fallback strategy for peaks (strict → A/σA union criterion + systematic error component).

→ feature_finder_precise details

Brute-Force Line Matching

Unified single-pass + Union-Find dedup

No longer separates QSO / ELG / LRG_BGS into three modes. All peaks + all troughs serve as anchors; each anchor computes a redshift, then matches all emission and absorption lines (unified tol_wavelength tolerance, default 80Å).

Union-Find dedup → sort by N_emission + N_absorption descending → output 7 fields (Hypothesis / z_max/min/spread / Emission/Absorption matches / N_em / N_abs).
