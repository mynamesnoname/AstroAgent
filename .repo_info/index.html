Multi-Agent Spectroscopy FORMA

An LLM-powered multi-agent system that reads astronomical spectra the way a human astronomer does. From a spectral FITS file, it digitizes the trace, detects emission and absorption features, generates redshift hypotheses through redrock, evaluates each hypothesis with independent LLM agents, cross-verifies them through adversarial review, and delivers a structured final report with calibrated confidence.

Scientific targets: source classification (QSO / GALAXY) and redshift measurement for survey spectra like DESI's.

Python 3.12 LangGraph LangChain DeepSeek-V4-Pro redrock PyWavelets CWT

Pipeline

Module 1, Step 1 Visual Interpreter

FITS channel.

  • Loads multi-band spectral data from FITS files.
  • Runs CWT wavelet feature detection to find emission peaks and absorption troughs.
  • Fits a Chebyshev continuum.
  • Uses redrock to generate redshift hypotheses.

PNG channel — in design.

Module 2Hypothesis Analyst
Step 2 Single-Hypothesis Evaluation
  • Analyse each hypothesis.
  • Produce a per-hypothesis report and an adopted feature catalog.
Step 4 Hypothesis Synthesis
  • Compare all per-hypothesis reports.
  • Deliver a structured verdict with the best hypothesis and supporting evidence.
Module 3Analysis Auditor
Step 3 Feature Auditor
  • Read spectrum, check adopted features, tell real features from noise.
  • Check doublet morphology, as well as other characteristics.
Step 5 Result Auditor
  • Conduct independent review of the Step 4 verdict.
  • Output a calibrated confidence: HIGH, MEDIUM or LOW, and a verdict: CONFIRM, NEEDS_REVISION, or UNCERTAIN. Raise possible issues.
Module 4, Step 6 Report Writer
  • Generate a structured report.
  • Produce a human-readable Markdown document for further analysis.
Module X, Step X · in design Self Evolve
  • Optional self-improvement loop, triggered when ground truth is available (from FITS metadata or environment variables).
  • Compares the synthesis verdict against ground truth; if they disagree, runs a two-round LLM analysis.
  • First round: blind review of the discrepancy without revealing which answer is correct. Second round: root-cause identification that pinpoints what went wrong.
  • Structured failure records are saved for batch analysis to identify systematic weaknesses across many spectra.
Tools
  • Supply tools for agents.
  • Focus on spectrum reading, calculating and knowledge searching in the knowledge base.
Knowledge Base
  • Contain knowledge used in inference and auditing, written in markdown files.
  • Accessed by agents through tools.
  • Knowledge can be modified and updated.

Feature Detection

CWT + Δχ² + global refinement

Peak and trough detection are fully symmetric. The pipeline:

1. Chebyshev continuum fit (mask features → fit → iterate)

2. CWT (Mexican Hat, scales 1–80) + smoothed residual dual-path candidate generation

3. Sliding-window Δχ² iterative joint fitting → cross-window deduplication

4. Global multi-Gaussian refinement with iterative outlier rejection

Troughs (absorption) are found first, then peaks (emission) — preventing wide emission lines from swallowing narrow absorption troughs. A two-pass fallback strategy for peaks (strict → A/σA union criterion + systematic error component).

→ feature_finder_precise details

Brute-Force Line Matching

Unified single-pass + Union-Find dedup

No longer separates QSO / ELG / LRG_BGS into three modes. All peaks + all troughs serve as anchors; each anchor computes a redshift, then matches all emission and absorption lines (unified tol_wavelength tolerance, default 80Å).

Union-Find dedup → sort by N_emission + N_absorption descending → output 7 fields (Hypothesis / z_max/min/spread / Emission/Absorption matches / N_em / N_abs).
