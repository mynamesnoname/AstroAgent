🔭 LLM-Spectro-Agent — Code Architecture

Project: LLM-powered multi-agent system for human-like analysis of 1D astronomical spectra

Framework: LangChain + LangGraph + MCP (Model Context Protocol)

Models: Qwen3-max (text), Qwen-vl-max (vision), via ChatOpenAI-compatible API

Tasks: Source classification (QSO / ELG / LRG-BGS) + Redshift estimation

Entry: scripts/main.py → WorkflowOrchestrator

Python 3.12 LangGraph LangChain MCP Jinja2 OpenCV PaddleOCR Pydantic

4. Agent Details

4.1 VisualInterpreter — run() pipeline

PhaseStepsMethod
FITS 通道 load_spectrum_from_fits: 多波段拼接 → quality mask → overlap mask → 高斯平滑 astropy + numpy + scipy (纯数值, 无 LLM)
PNG A: 坐标轴 VLM detect → OCR detect → LLM combine → LLM revise VLM(qwen-vl-max) + PaddleOCR/Tesseract + LLM keep/reject
PNG B: 裁剪 迭代检测边框 → 裁剪 → VLM check_border → 重试直到四边干净 OpenCV + VLM gate; MAX_MARGIN=30px
PNG C: 光谱重建 remap ticks → pixel_to_value(加权线性拟合) → convert_to_spectrum OpenCV 轮廓检测 + 列平均 + SNR 估计
D: 特征检测 run_iterative_feature_detection(): CWT + 多尺度Gaussian → 迭代Δχ²模型构建 → 全局精炼 PyWavelets + 自定义 Gaussian fitting + 动态阈值
E: Continuum mask features → Chebyshev polynomial fit → monotonic region description specutils + degree 自动选择
F: 暴力匹配 全部峰+谷锚定 → 全部发射线+吸收线匹配 → 统一 Union-Find 去重 → 7字段输出 单次通过, tol_wavelength (默认80Å)

9. Feature Detection Algorithm (找峰/找谷)

CWT + Δχ² + 全局精修

找峰/找谷算法完全对称设计。核心流程：Chebyshev continuum 拟合 → CWT (Mexican Hat, scales 1-80) + Smoothed residual 双路候选 → 滑动窗口 Δχ² 迭代联合拟合 → 跨窗口去重 → 全局 multi_gaussian 精修迭代剔除。

先找谷（吸收线）再找峰（发射线），避免宽发射线吞掉窄吸收谷。找峰有两遍回退策略（严格 → A/σ_A 并集判据 + 系统误差分量）。

10. Brute-Force Line Matching (统一暴力线匹配)

统一单次通过 + Union-Find 去重

v2026-05 重构: 不再区分 qso/elg/lrg_bgs 三模式。使用全部峰 + 全部谷作为锚点，每次锚定计算红移后匹配所有发射线和吸收线（统一 tol_wavelength 容差）。Union-Find 去重后按 N_emission + N_absorption 降序排列。

输出精简为 7 字段（Hypothesis, z_max/min/spread, Emission/Absorption matches, N_emission, N_absorption）。旧三模式代码已注释保留。
