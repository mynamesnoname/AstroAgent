1. Design Rationale

§Design rationale (L311–317)

来源: DESI collaboration 成员结构化访谈 + VI protocol 文档分析。

专家工作流三阶段:

  1. Parse — 图形表示 → 量化可观测值
  2. Hypothesize — 连续谱形态 + 线宽模式 → 初步物理假设
  3. Test — 预测关联谱线位置 → 检查多线红移一致性
z_i = λ_obs,i / λ_rest,i − 1 (Eq. 1) 评估所有 z_i 之间的一致性.

核心洞察: DESI VI 界面中专家切换第 N 个 Redrock fit 时，不是被动接受输出，而是在做 快速假设驱动的线匹配——用模型叠加作为参考来验证/挑战自己的解读。

FORMA 将 感知解析 + 物理约束假设生成 + 对抗性自我批判 这个认知模板形式化。

关键设计原则:

  • Perception / physical interpretation / numerical computation / critical review 在不同的约束下运行——单一 LLM 无法同时满足 (会过早收敛到 plausible-but-incorrect 的解, 产生 spurious consistency, 在 λ→z 转换中犯算术错误)
  • 数值计算与 LLM 推理隔离: 所有波长→红移转换和容忍度线匹配在 hypothesis enumeration 阶段预计算为权威输入; 唯一运行时数值操作——红移不确定性传播——委托给一个 MCP tool

3.2 Feature Candidate Generation

核心算法: CWT (Mexican-hat; PyWavelets) + 多尺度 Gaussian 平滑定位候选特征 → 迭代 Δχ² 模型构建 → 全局 multi-Gaussian 精炼

  • 吸收线先于发射线处理 (narrower profiles, less blending)
  • 每个候选按振幅降序测试; 当 Δχ² 低于动态阈值(随模型复杂度增大)时停止迭代 → 自然正则化
  • 系统误差项补充 formal pipeline variance → 捕获校准不完美
  • Joint 全局精炼 → 按 FWHM 分类: narrow (<1,000 km/s) / intermediate / broad (≥2,000 km/s)
  • Quality flags: low significance / boundary proximity / large fitting errors / blending / low SNR depth
  • Iterative detect-and-mask 回收强线翼中的弱线
  • 典型中心波长不确定性: 10⁰–10¹ Å → 红移不确定性: 10⁻²–10⁻³

3.3 Continuum Fitting

  • Mask detected features → Chebyshev polynomial fit (specutils)
  • Degree 自动选择: 权衡 residual scatter + skewness + model complexity
  • 分区为近 monotonic intervals → 自然语言 blue-to-red slope 描述 → 下游 QSO (blue-rising) / galaxy (red-rising) 先验

3.4 Exhaustive Hypothesis Enumeration

模拟 DESI VI 模板滑动流程。每个检测到的 feature 轮流锚定到每条 rest-frame atomic line:

  • 计算隐含 redshift → 寻找 tolerance 内的支持匹配 (QSO: 100Å, galaxies: 30Å)
  • Emission features ↔ emission lines only; absorption features ↔ absorption lines only
  • De-dup: co-occurring (feature, line) pairs → connected components
  • 三模式并行:
    1. QSO: all peaks vs UV/optical BLR+NLR emission lines
    2. ELG: narrow peaks only vs full emission line list
    3. LRG/BGS: narrow peaks + absorption troughs; BLR-broad excluded
  • 典型产出: K ~ 10–20 hypotheses per spectrum
  • 每个 hypothesis 携带: redshift range, matched features, individual redshifts & widths (FWHM in Å and km/s), width-mismatch warnings, missing-line catalog, Dn(4000)

4.2 Quantitative Analysis — Step F Pipeline

三条类型特定管道 (QSO, ELG, LRG/BGS), 每条: 独立逐假设 → 跨假设综合 (先各自评估, 防止过早收敛)

Step F-a: Per-hypothesis Physical Reasoning

三条子步骤: F-1 假设内容描述 → F-2 物理验证 → F-3 结论

PipelineKey DiagnosticsConstraints
QSO Case 1 (broad-line): Lyα, CIV, CIII], MgII
Case 2 (host-AGN): NeV, CIII], MgII, [OIII] doublet		 振幅比 (Lyα ≮ MgII); 线宽-类型约束 (narrow feature + BLR-broad line → flagged); missing-line catalog 解读
ELG [OII], [OIII] doublet, Hα, Hβ Narrow-line prior: broad feature → scrutinized as fitting artefact
LRG/BGS Absorption lines, Dn(4000) break, narrow emission lines Broad features masked out; 两吸收线间 continuum 可能误检为 broad emission

Step F-b: Type-based Cross-hypothesis Synthesis

所有 per-hypothesis summaries + 完整线匹配数据 → intra-type comparison:

评估优先级: physical coherence > missing-line impact > width-mismatch severity > continuum consistency > adopted-pair plausibility

淘汰条件: active redshift warnings + weak evidence; collapse to single line; unresolvable width mismatches. 输出 ≤ 2 最佳假设或 "Cannot confirm".

Concurrency Strategy

首条假设串行 (预热 KV-cache) → 剩余 Semaphore(STEP_F_CONCURRENCY-1) 并发; Step F-extract 流水线化 (每个假设的 extract 紧跟其 F-a); Step F-b 串行 (需要所有 summaries).

5. Auditor & Refinement (Modules 3–4)

§Spectral Auditor and Refinement — Critical Review Modules (L393–410)

PhaseModuleActionKey Detail
1 Auditor Per-path critique 每条假设生成 1–4 条挑战, 优先级顺序: (1) 线宽自洽性 (2) 独立约束数量 (3) 关键诊断线缺失 (4) 路径内竞争. 评估 adopted line combination 整体结构一致性, 不重新验证单个线匹配.
2 Refinement Per-path response 逐条回复: invalid challenges → refuted with explanation; valid concerns → acknowledged with mitigating factors. 不修改假设内容 — 为裁决提供 scrutiny 上下文.
Loop Both Multi-round iteration 默认 1 轮, 可配置. Auditor 接收累积 debate history, 不重复 adequately addressed challenges. 三条路径全 null → 跳过循环.
3 Auditor Cross-type verdict 跨类型比较三条路径最终假设 → 选 1–2 最佳候选. 权重: physical coherence + missing-line impact + width-mismatch severity + debate record strength. 无达标假设 → "Cannot confirm".
4 Refinement Final report synthesis 综合所有上游产物 + 完整 debate record → 结构化最终报告. 唯一调用 MCP 工具的一步: calculate_rms_for_redshift_tool(λ_rest, σ_λ) → σ_z.

6. Synthesis Host (Module 5)

§Spectral Synthesis Host (L412–414)

  • 从 final_report 和 cross-type verdict 提取结构化 catalog entries
  • 两个并发 LLM 调用: in_brief_primary (主) 和 in_brief_2nd (次, 仅在物理类型或红移显著不同于主时)
  • 固定 JSON schema 输出: object type, credibility score, redshift ± uncertainty, identified lines
  • 仅做信息提取, 不调用 MCP, 不引入新推理
  • 字段映射: type, score, redshift, redshift_rms, lines, human, type_2nd, redshift_2nd, redshift_rms_2nd, lines_2nd

7. Output Structure & Credibility Calibration

§Output structure and credibility calibration (L416–430)

Final Report — 6 Sections

  1. Basic spectral information — wavelength coverage, continuum morphology, qualitative line-feature description
  2. Preliminary classification and rationale
  3. Per-path quantitative analysis summaries — 每条有效假设: physical type, confidence, suggested redshift, key evidence
  4. Cross-type adjudication — primary (和 optional secondary) hypothesis + adopted line pairs + evidence + remaining doubts
  5. Comprehensive assessment — final object type, redshift±uncertainty, identified lines, credibility score, manual-review recommendation
  6. Concise natural-language conclusion

Credibility Score (0–4, adapted from DESI VI)

ScoreMeaning
4Confident classification — ≥2 secure features
3Probable classification — ≥1 secure feature + continuum support, or many weak features
2Possible classification — 1 strong emission feature, identity uncertain
1Unlikely classification — ≥1 unidentified features
0No signal — nothing detected

Downgraded Inference Procedure

定量分析无有效假设时触发: 最强峰(按振幅排名) + 宽度类别 + continuum 形态 → 规则驱动分类 → provisional object type, 无红移/线鉴定, score ≤ 1 → 标记人工审查.

Manual-review recommendation 触发条件: score ≤ 2, 或 downgraded inference, 或 remaining doubts 含 critical unresolved concerns.

8. Numerical Computation — MCP Tool Server

§Numerical computation (L432–440)

唯一 MCP Tool:

calculate_rms_for_redshift_tool(λ_rest, σ_λ) → σ_z = σ_λ / λ_rest

设计理由: 所有其他数值操作 (redshift calculation, observed-wavelength projection, tolerance matching) 在 exhaustive line matching 阶段 预计算 为 LLM 的权威输入字段。Report time 仅剩的不确定性操作是 uncertainty propagation——取决于 LLM 选择的 anchor line → 一个 tool 足够。

10. Data Characteristics

§Data Characteristics and Performance Statistics (L492–505)

DESI EDR VI Dataset

来源: DESI EDR VI value-added catalogs (SV1 deep co-added spectra). 约 22,000 spectra: BGS(2,718) + LRG(3,561) + ELG(10,315) + QSO(3,779) + missed-QSO(1,717).

构建流程 (5 steps):

  1. 按 SPECTYPE 提取: QSO from QSO+missed-QSO; ELG/LRG/BGS from respective catalogs (SPECTYPE=GALAXY)
  2. TARGETID+TILEID+RA+DEC 匹配 coadded FITS spectrum
  3. 读 B,R,Z arm median SNR → SNR_sum
  4. 按 SNR_sum 降序 → 4:4:2 stratified (high/medium/low) → 每类随机抽样 300
  5. ELG/LRG/BGS 重复; BGS 可用数量限制 → 最终 249

Final: 1,149 spectra = 300 QSO + 300 ELG + 300 LRG + 249 BGS

[橙色 backup] CSST Slitless Mock: 10,000+ spectra 全集, 4 SNR 分组 (good 40% / medium 40% / poor 20%), 20 QSOs + 20 LRGs. 适配 CSST 仪器特征.
[橙色 backup] Original DESI Observational Data: HEALPix pixel 23040, 按 FLUX_G 排序, 4:4:2 stratification. 20 QSO (10 observed+10 mock) + 10 ELG +10 LRG.
