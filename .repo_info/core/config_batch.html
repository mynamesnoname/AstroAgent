parse_batch_range

parse_batch_range(start: str, end: str) -> List[str]

Module-level helper. Converts a numeric string range into a list of string IDs:

1. Validates both start and end are numeric digits.
2. Ensures start ≤ end.
3. Detects zero-padding: if start has a leading zero and is wider than its integer value, uses fixed-width zero-padded output (e.g. ("001","005") → ["001","002","003","004","005"]).
4. Otherwise, generates plain integer strings (("1","5") → ["1","2","3","4","5"]).

→ List[str] — ordered list of numeric ID strings

class BatchConfig

class BatchConfig(BaseModel)

Pydantic model with three fields: header: str (optional prefix, e.g. "spec-"), start: Optional[str], end: Optional[str]. Both start/end are validated via @field_validator to be numeric digits if non-None.

Agents use this config to determine whether the system is in single-file or batch mode — if both start and end are set, generate_ids() produces the full file ID list.

from_env

@classmethod from_env() -> BatchConfig

Construct from environment variables: FILE_BATCH_HEADER (default ""), FILE_BATCH_START, FILE_BATCH_END. If start/end are not set, they remain None, putting the system in single-file mode.

→ BatchConfig instance

validate_digit

@field_validator("start", "end") validate_digit(v) -> Optional[str]

Pydantic field validator. If v is None, passes through. Otherwise asserts v.isdigit() — raises ValueError on non-numeric batch start/end values.

is_batch_mode

is_batch_mode(self) -> bool

Returns True only when both start and end are non-None. Controls whether the system generates a file ID list or uses the single FILE_NAME from IOConfig.

→ bool

generate_ids

generate_ids(self) -> List[str]

If batch mode is active, calls parse_batch_range(start, end) and prefixes each index with self.header (e.g. ["spec-001", "spec-002", ...]). Returns empty list if not in batch mode.

→ List[str] — ordered file IDs, or []
