Module-Level Functions

_detect_vendor

_detect_vendor(base_url: str) -> str

Inspect the API base URL to determine the LLM vendor. Used by downstream functions to emit vendor-specific API parameters.

→ 'deepseek' if url contains 'deepseek' · 'qwen' if url contains 'aliyuncs' / 'dashscope' / 'qwen' · 'unknown' otherwise

_build_thinking_extra_body

_build_thinking_extra_body(mode: str, vendor: str) -> dict | None

Build the thinking/reasoning parameter payload for the target vendor:

deepseek → {"thinking": {"type": mode}} (mode = 'enabled' | 'disabled')
qwen → {"enable_thinking": True/False}
unknown → None (skip to avoid parameter rejection)

_create_chat_openai

_create_chat_openai(model, api_key, base_url, temperature=0.1, max_tokens=None, streaming=False, extra_body=None) -> ChatOpenAI

Create a ChatOpenAI instance with vendor-specific patches:

DeepSeek max_tokens patch — langchain-openai ≥1.x renames max_tokens → max_completion_tokens for OpenAI API compat. DeepSeek only recognises max_tokens and silently falls back to its default (8192) when it receives max_completion_tokens. This function monkey-patches _get_request_payload on the instance to reverse the rename before the request is sent.

→ ChatOpenAI instance (possibly patched)

create_client

create_client(self) -> ChatOpenAI

Build the ChatOpenAI client from stored config:

thinking modes:
'none' — skip thinking params entirely (for models like qwen-vl-max that don't support them)
'disabled' — explicitly disable; base_agent may later bind-override to 'enabled' when want_tools=False
'enabled' — enable thinking; base_agent will bind-override to 'disabled' when want_tools=True (preserving multi-turn tool-call safety)

→ ChatOpenAI instance, ready for LangChain agent binding
Why the DeepSeek patch? langchain-openai rewrites max_tokens to max_completion_tokens on every request. DeepSeek's API ignores the renamed field and uses its own default (8192). Without this patch, max_tokens configuration is silently dropped for all DeepSeek calls — the agent may appear to work but produces truncated or unexpectedly short completions.
