class AllConfig

class AllConfig(BaseModel)

Top-level Pydantic model with six fields:

  • batch : BatchConfig — batch range & file ID generation
  • io : IOConfig — input/output directories, run mode (s / b), file name
  • model : ModelConfig — LLM and VLM API parameters (key, url, model, temperature, thinking, stream)
  • params : ParamsConfig — science parameters (spectral arms, CWT thresholds, Redrock config, concurrency, SelfEvolve flags)
  • retry_delay : int — seconds to wait between connection/timeout retries (env: RETRY_DELAY, default 180)
  • max_tries : int — maximum retry attempts for connection/timeout errors (env: MAX_TRIES, default 3)

from_env

@classmethod from_env() -> AllConfig

The single entry point for configuration. Chains all sub-config factories:

1. BatchConfig.from_env() → batch
2. IOConfig.from_env() → io
3. ModelConfig.from_env() → model
4. ParamsConfig.from_env() → params
5. RETRY_DELAY env var (default 180) → retry_delay
6. MAX_TRIES env var (default 3) → max_tries

Each sub-config factory performs its own validation (field-level + cross-field). Any validation error propagates up to prevent the system from starting with invalid configuration.

→ AllConfig instance (fully validated)
Why aggregate into one class? The entire configuration tree is a single object passed through the system. scripts/main.py calls AllConfig.from_env() once, then passes it to RuntimeContainer, WorkflowOrchestrator, and every agent. This ensures all components share a consistent, validated configuration without scattered env-var reads.
