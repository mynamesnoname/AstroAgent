class ModelConfig

class ModelConfig(BaseModel)

Holds two dict fields — llm and vlm — each containing the full parameter set for a ChatOpenAI client:

KeyTypeSource Env VarDescription
api_keystrLLM_API_KEY / VLM_API_KEYAPI authentication key
base_urlstrLLM_BASE_URL / VLM_BASE_URLAPI endpoint URL
modelstrLLM_MODEL / VLM_MODELModel name (e.g. qwen3-max)
temperaturefloatLLM_TEMPERATURE / VLM_TEMPERATURESampling temperature (default 0.1)
max_tokensOptional[int]LLM_MAX_TOKENS / VLM_MAX_TOKENSMax completion tokens (None = unlimited)
thinkingstrLLM_THINKING / VLM_THINKINGThinking mode: "disabled" / "extended" / etc.
streamboolSTREAM (shared)Streaming flag (shared between LLM and VLM)

Both llm and vlm dicts are validated to have non-empty api_key, model, and base_url — raises ValueError if any are missing.

from_env

@classmethod from_env() -> ModelConfig

Construct from environment variables. Contains a nested parse_max_tokens() helper that safely converts the env var string to Optional[int] (returns None on parse failure with a warning).

Process:

  • Parse STREAM via safe_to_bool() → shared across LLM and VLM
  • Build llm dict from LLM_* env vars (temperature defaults to 0.1)
  • Build vlm dict from VLM_* env vars (temperature defaults to 0.1)
  • Validate: raise ValueError if api_key, model, or base_url are empty for either
  • Return ModelConfig(llm=llm, vlm=vlm)
→ ModelConfig instance (validated)

to_dict

to_dict(self) -> Dict[str, Any]

Serialize the model config to a plain dict via self.model_dump(). Returns {"llm": {...}, "vlm": {...}}.

→ Dict[str, Any] — serialized config
How this feeds into llm.py: RuntimeContainer.get_model(type) looks up configs.model.llm or configs.model.vlm and passes the dict to ThisIsModel(config).create_client(), which unpacks the dict into a ChatOpenAI(...) constructor.
