class IOConfig

class IOConfig(BaseModel)

Pydantic model with five fields:

  • input_dir : str — directory containing input spectrum files
  • input_format : str — file format tag (e.g. "png", "fits")
  • output_dir : str — directory for result output
  • run_mode : str — 's' for single-file, 'b' for batch
  • file_name : Optional[str] = "" — single-file name (required when run_mode='s')

validate_by_mode

@model_validator(mode='after') validate_by_mode(self) -> IOConfig

Cross-field validation executed after all fields are populated:

  • Base check: input_dir, output_dir, run_mode must all be non-empty — raises ValueError otherwise.
  • Mode check: run_mode must be exactly 's' or 'b' — raises ValueError on invalid values.
  • Single-mode check: when run_mode == 's', file_name must be non-empty — raises ValueError otherwise.
  • Batch mode: file_name is optional, no additional validation.
→ self (validated IOConfig instance)

from_env

@classmethod from_env() -> IOConfig

Construct from environment variables:

  • INPUT_DIR → input_dir (default "")
  • INPUT_FORMAT → input_format (default "")
  • OUTPUT_DIR → output_dir (default "")
  • RUN_MODE → run_mode (lowercased, default "s")
  • FILE_NAME → file_name (default "")

After construction, validate_by_mode() runs automatically to enforce mode-specific requirements.

→ IOConfig instance (validated)
