CoreConfig Overview

Path: src/AstroAgent/core/config/ (6 files, 5 Pydantic models + _utils)

Configuration system — aggregates all runtime parameters via Pydantic models loaded from environment variables. Each model has a from_env() classmethod factory with field-level and cross-field validation.

Classes: AllConfig · BatchConfig · IOConfig · ModelConfig · ParamsConfig · _utils (helpers)

core config Pydantic

Contents

  1. AllConfig — top-level aggregator
  2. BatchConfig — batch range & file ID generation
  3. IOConfig — I/O paths & run mode validation
  4. ModelConfig — LLM + VLM client parameters
  5. ParamsConfig — science & pipeline parameters
  6. _utils — env-var parsing helpers

class AllConfig

Inherits: BaseModel

Top-level config aggregation. Composes BatchConfig, IOConfig, ModelConfig, ParamsConfig plus retry_delay and max_tries. The single from_env() factory chains all sub-factories. → Full details

class BatchConfig

Inherits: BaseModel

Batch processing config: header prefix, numeric start/end range with field validation, is_batch_mode() detection, generate_ids() file list generation. → Full details

class IOConfig

Inherits: BaseModel

I/O path config: input_dir, input_format, output_dir, run_mode (s/b), file_name. Cross-field validation ensures mode-specific required fields are present. → Full details

class ModelConfig

Inherits: BaseModel

LLM/VLM client configuration: two dicts (llm, vlm) each with api_key, base_url, model, temperature, max_tokens, thinking mode, and streaming flag. → Full details

class ParamsConfig

Inherits: BaseModel

Science & pipeline parameters: spectral arms, CWT feature detection thresholds, Redrock redshift engine config, harness concurrency, SelfEvolve flags. 24 fields in 3 groups. → Full details

module _utils
