main

async main() -> None

Top-level async entry point. Orchestrates the full processing lifecycle:

  • Config bootstrap — load_dotenv() + AllConfig.from_env() loads all Pydantic config models from environment variables
  • Factories — creates SpectroStateFactory (builds initial state per spectrum) and ResultWriter (disk persistence)
  • Input resolution — in batch mode (run_mode='b') calls batch_config.generate_ids(); in single mode uses io_config.file_name
  • Orchestrator init — instantiates WorkflowOrchestrator(configs), which initializes all 6 agents and compiles the LangGraph StateGraph
  • CSV bootstrap — writes header row to in_brief.csv (8 columns: file_name, type, signal_clarity, redshift, redshift_rms, lines, confidence, human_review)
  • Processing loop — for each file_id: build SpectroState → run pipeline → write results → append CSV row → optionally trigger batch failure analysis when SelfEvolve accumulates enough pending failures
  • Final flush — if SelfEvolve is enabled, processes any remaining pending failures that didn't reach batch_size

safe_str

safe_str(x) -> str

Nested helper inside main(). Converts None, NaN, or Inf to the string "N/A"; all other values pass through str(x). Used when building CSV rows to avoid broken numeric literals.

if __name__ == "__main__"

logging.basicConfig(…) + asyncio.run(main())

Configures root logger with timestamped [LEVEL] format at INFO level, then launches the async main() coroutine via asyncio.run().

Batch failure analysis (SelfEvolve): When params.self_evolve is enabled and a pipeline run records a failure, the pending failure count is checked against params.failure_batch_size. Once the threshold is met, analyze_failure_batch() from utils/HA.py is invoked asynchronously to perform root-cause analysis across the failure batch.
