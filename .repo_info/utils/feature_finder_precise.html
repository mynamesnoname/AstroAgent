9. Feature Detection Algorithm (找峰/找谷)

实现文件: src/AstroAgent/agents/multi_agents/utils/feature_finder_precise.py

调用入口: VisualInterpreter.run() → run_iterative_feature_detection()

核心思路: CWT 多尺度初筛 + 滑动窗口 Δχ² 联合拟合 + 全局精修迭代剔除。找谷和找峰算法完全对称设计。

9.2 为什么先找谷再找峰？

吸收线通常比发射线窄且深，在 residual 中信号更明确。先把谷找出来 mask 掉（中心 ±3σ），可以避免宽发射线"吞掉"旁边的窄吸收谷。然后在去掉吸收线的光谱上找发射峰，减少干扰。

9.3 共享基础设施

Chebyshev 自动选阶 (select_chebyshev_degree)

遍历 min_degree~max_degree，取 MAD×10 + (skew−0.5)²×5 + deg×0.2 最小的阶数。MAD 衡量残差离散度，skew 偏好轻微偏斜的残差分布（理想约 0.5），deg 项防止过拟合。

误差准备 (_prepare_sigma)

优先级: ivar > effective_snr > 默认 SNR=7。支持附加连续谱系统误差分量（参考 DLA-Toolkit var_lss）：σ_eff² = σ_pipe² + (continuum × ε)²。仅在找峰第二遍回退时启用（ε=sys_err_frac，典型 0.02~0.05）。

质量控制标志 (bitwise flags)

Flag含义
FLAG_LOW_DELTA_CHI2 (1)Δχ² 低于警告阈值
FLAG_BOUNDARY (2)参数触碰边界 (FWHM/振幅越界)
FLAG_BAD_ERROR (4)参数误差过大或拟合异常
FLAG_BLEND (8)与相邻线混叠
FLAG_LOW_SNRS (16)深度信噪比过低（仅吸收线）

宽窄分类

FWHM_km_s < 1000 → narrow; 1000-2000 → intermediate; > 2000 → broad

9.4 找峰: find_emission_lines() — 五个步骤

Step 1: Continuum 拟合

Chebyshev 多项式拟合→ residual = flux − continuum。所有后续操作在 residual 上进行。

Step 2: 双路候选峰生成

候选源方法目标
CWT 候选 Mexican Hat 小波 (scales 1-80) → 取各尺度最大响应 → find_peaks 窄/中等宽度峰，信噪比高
Smoothed 候选 对 residual 做大核高斯平滑 (σ=16) → find_peaks (prominence=0.1×range) 宽低振幅峰——CWT 单尺度不显著，但 smoothed 整体形态明显

候选优先级: Smoothed 候选 > CWT 候选。Smoothed 振幅下界检验更宽松（大核平滑压低峰值）。sigma 初始估计 = (scipy 半高宽 / 2.355) × 平均波长间距 × 0.85（退卷积修正）。

Step 3: 滑动窗口迭代拟合 (核心)

窗口 500Å，重叠 300Å。每窗口内：

  1. 拟合 null model（纯线性基线），得 χ²₀
  2. 依次添加候选峰，拟合 multi_gaussian + 线性基线，得 χ²₁
  3. 计算 归一化 Δχ² = (χ²₀ − χ²₁) / N_points
  4. 动态阈值: threshold = base × (1 + factor × n_accepted)——接受线越多，新候选门槛越高

接受条件链（全部通过才接受）

  1. Δχ² ≥ threshold
  2. 振幅 ∈ [0.8×residual@center, 1.5×residual@center]（smoothed 候选跳过下界）
  3. FWHM ∈ [fwhm_min, fwhm_max]
  4. 参数相对误差 < 50%
  5. 不与已接受峰混叠: 距离 ≥ blend_k × min(fwhm₁, fwhm₂)

混叠策略: 新峰与已接受峰冲突时，保留更宽的——宽峰更可能是物理的 BLR 发射线。

Step 4: 跨窗口去重

重复峰（中心距离 < 5Å）→ 保留 Δχ² 更大的。

Step 5: 全局精修 (迭代剔除)

将所有候选放入全局 multi_gaussian 模型联合拟合。逐峰计算局部 Δχ²（中心 ±150Å 窗口内 null vs null+gaussian 的 χ² 差）。剔除不达标峰，重复直到收敛。

两遍策略 (fallback)

第一遍第二遍
判据严格 Δχ² 阈值A/σ_A ≥ 3 并集 Δχ²（降低弱信号漏检）
系统误差分量无σ_sys = continuum × sys_err_frac
触发条件始终执行第一遍结果 < 2 条

9.5 找谷: find_absorption_lines() — 与找峰的差异

方面找峰 (Emission)找谷 (Absorption)
信号方向residual 正值residual 负值
CWT 输入residual−residual（取反后找峰）
拟合模型gaussian(amp, μ, σ)inverted_gaussian(amp, μ, σ) (向下凹陷)
局部基线全局 continuum 的残差窗口内独立拟合局部 continuum (Chebyshev + σ-clipping 迭代)
额外条件—中心残差必须 < 0; 深度 SNR ≥ 3.0
混叠策略保留宽峰保留窄谷（窄吸收线更物理）
Smoothed 振幅检验跳过下界同时跳过下界和上界（谷展宽低平）
窗口宽度500Å100Å（吸收线更窄）
为什么吸收线需要独立拟合局部 continuum？
吸收线所在区域的连续谱可能被宽发射线扭曲，全局 continuum 的残差在局部不是好的零基线。因此在每个窗口内独立 fit 局部 continuum（Chebyshev + σ-clipping 迭代剔除吸收线点），然后在其局部残差上做 Δχ² 检验。

9.6 迭代检测 (iterative_emission/absorption_detection)

每轮将已检测特征区域（中心 ±3σ）从波长数组中删除，在剩余光谱上继续检测。默认 3 轮，某轮无新检测时提前终止。ivar/snr 数组同步 mask 以保持与波长数组一致。

9.7 Pseudopeak 标注

发射线中心 ±3σ 范围内覆盖的谷数量 ≥ pseudo_trough_threshold（默认 2）时，标记为伪峰（broad emission line 吃掉窄吸收线的情况）。
