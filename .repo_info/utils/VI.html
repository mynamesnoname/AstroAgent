1. OCR / 坐标轴刻度检测

1.1 Tesseract (_detect_axis_ticks_tesseract, line 25)

对图像做 Gaussian 模糊 + 自适应阈值二值化，用 Tesseract 逐字识别数字。过滤出可转为 float 的文本，输出 (value, pixel_position, bbox_scale) 三元组。

Tesseract 在光谱图上的数字识别效果较差。代码注释中标注 "Tesseract is not good. I prefer paddle."

1.2 PaddleOCR (_detect_axis_ticks_paddle, line 63)

使用 PaddleOCR 直接对整个图像做文字检测+识别（关闭文档方向分类和去翘曲），输出所有识别文本的中心坐标和包围盒尺寸。结果同时保存为图像和 JSON。

2. 边框检测与图像裁剪

2.1 _detect_chart_border (line 96)

二值化 → 形态学闭运算去噪 → 找最大轮廓 → 按 margin 微调。返回 {x, y, w, h}。

参数: image_path, margin dict (默认 top=10/right=10/bottom=10/left=10)

2.2 _crop_img (line 146)

按 border_info 裁剪图像并保存。简单的 numpy slicing: img[y:y+h, x:x+w]。

2.3 迭代裁剪 (VisualInterpreter.border_detection_and_cropping)

裁剪后用 VLM 检查四边是否干净（无残留坐标轴/刻度/文字），不干净则增加对应边 margin（每次 +2px），直到四边都通过或 margin 达到上限 30px。

3. 像素坐标重映射与拟合

3.1 _remap_to_cropped_canvas (line 178)

将原图坐标系中的刻度位置映射到裁剪后的画布坐标: (ox - x0, oy - y0)，超出画布范围的 clamp 到边界。同时兼容 None 坐标。

3.2 _pixel_tickvalue_fitting (line 209)

对 x/y 轴分别做 加权线性拟合 (scipy curve_fit): value = a * pixel + b。权重 = sigma_pixel / sqrt(conf_llm)。输入至少 2 个点，输出 a, b, rms, residuals。

4. 曲线提取与光谱重建

4.1 _process_and_extract_curve_points (line 265)

读取裁剪后的图像 → 转灰度 → 阈值 200 二值化 (THRESH_BINARY_INV)，白色区域的像素点即为光谱曲线点云。返回 (x, y) 坐标列表和灰度值列表。

4.2 _convert_to_spectrum (line 325)

像素点云 (x, y) │ ├── a_y × y + b_y → flux ├── a_x × x + b_x → wavelength │ ├── [optional] 波段重叠区域去除 (find_overlap_regions) │ └── 删掉落在重叠区的点 │ └── average_flux_by_wavelength() : 同波长取均值 │ └── spectrum_dict: wavelength, flux, snr, max/min_unresolved_flux

返回 spectrum_dict: {wavelength, flux, max_unresolved_flux, min_unresolved_flux, snr}。SNR 估计: SNR = mean_flux / std_flux (逐波长)。

5. FITS 光谱加载 (_load_spectrum_from_fits, line 421)

签名: _load_spectrum_from_fits(fits_path, arm_names, arm_wavelength_ranges) → dict

返回 spectrum_dict: {wavelength, flux, snr, ivar} — ivar 为 None 时 SNR 从 flux × sqrt(ivar) 计算。

不再接收 state 参数，state 赋值由 VisualInterpreter agent 层完成。

支持两种 FITS 格式：

格式结构示例
多波段分波段每个波段独立的 WAVELENGTH/FLUX/IVAR/MASK HDUDESI (B,R,Z), CSST (U,V,I)

多波段管线

读取各波段 WAVELENGTH / FLUX / IVAR / MASK │ ├── quality_mask = (specmask == 0) & (ivar > 0) ├── overlap_mask: 去除波段重叠区 ├── 应用 keep_mask → 按波长排序 → 同波长去重(取均值) └── 高斯平滑 (sigma=2) │ └── spectrum_dict: {wavelength, flux, snr, ivar}

6. Continuum 拟合

6.1 run_continuum_fitting (line 744)

签名: run_continuum_fitting(wavelengths, flux, chebyshev_degree, ...) → (continuum_dict, residual_spectrum_dict)

不再接收 state，直接接受数组，返回两个 dict。State 赋值在 agent 层。

用 specutils 的 Chebyshev1D 多项式拟合连续谱。阶数可手动指定或自动选择（通过 select_chebyshev_degree）。计算对数导数 dlnF/dλ，根据导数符号划分单调区间，生成自然语言描述。

6.2 run_continuum_fitting_masked (line 902)

签名: run_continuum_fitting_masked(wavelengths, flux, peaks, troughs, ...) → (continuum_dict, residual_spectrum_dict)

先用已检测到的峰/谷区域（中心 ±3σ，σ = FWHM_A / 2.355）mask 掉特征区域，然后在剩余"干净"光谱上拟合 continuum。可用点数 < 20 时回退为全谱拟合。拟合后在完整波长数组上插值评估。

6.3 generate_continuum_description (line 825)

根据 monotonic regions 生成自然语言描述，例如：
"The continuum has a value of 2.027 at 4000.0 Å, monotonically increases from 4000.0 Å to 5010.1 Å, reaching 3.499 at 5010.1 Å; ..."

8. 暴力线匹配 (brute_force_line_matching, line 1563)

签名: brute_force_line_matching(state, tol_wavelength=None) → list[dict]

目的: 对已检测到的峰/谷做物理谱线标注，生成红移假设供 LLM 做定量分析

静止系谱线表: 18 条发射线 (Lyα ~ S[II]b) + 15 条吸收线 (Ca K/H ~ Hα_abs)

v2026-05 重构: 统一单次通过模式（不再区分 qso/elg/lrg_bgs），使用全部峰 + 全部谷锚定，吸收线锚定始终启用。输出简化为 7 个字段。

8.1 三相流程

Phase 1: 逐峰逐线锚定 + 逐谷锚定

对每个峰，假设它是某条发射线，计算红移 z = λ_obs / λ_rest − 1。用 z 预测所有其他谱线位置，在 tol_wavelength 容差内匹配峰和谷。

对每个谷，假设它是某条吸收线，同样计算红移并验证其余谷和峰。

每条匹配记录为 (obs_wl, line_name, z) 三元组。匹配来源以波长所属（peak/trough）为准，而非仅凭谱线名——Mg II 等线同时存在于发射线与吸收线表。

Phase 2: Union-Find 去重

节点 = (wavelength, line_name) 对。同一假设内所有节点互联（union）。每个连通分量 = 一个独立的物理场景。路径压缩优化。

Phase 3: 格式化输出 + 过滤

按 N_emission + N_absorption 降序排列。有效独立约束数 < 1 的假设被丢弃。

8.4 发射线/吸收线宽窄分类

Broad (BLR 宽线区)

  • Lyα (1216.0)
  • C IV (1549.0)
  • C III] (1909.0)
  • Mg II (2800.0)

Both (BLR+NLR)

  • He II (1640.4)
  • Hε, Hδ, Hγ, Hβ, Hα (Balmer)

Narrow (NLR 窄线区)

  • Ne [V] (3426.0)
  • O [II] (3727.0)
  • O [III]a/b (4960/5008)
  • N [II]a/b (6550/6585)
  • S [II]a/b (6718/6733)

8.5 宽度不匹配警告

宽线 (Lyα, C IV, C III], Mg II) 配窄峰 或 窄线 ([O III], [N II] 等) 配宽峰 → ⚠ width mismatch。"both" 类 (Balmer系, He II) 和 "intermediate" 类跳过此校验。
