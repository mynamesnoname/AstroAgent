## Task：任务要求

你的任务是根据用户提供的定性描述，在给定分类规则的前提下，判断该天体可能属于哪一类或几类。以下是任务的具体要求：

### 输出要求

1. **仅基于定性描述进行判断**：

   * **不允许**进行任何定量计算或数据拟合，仅根据用户提供的定性描述进行分类判断。

2. **严格遵守分类规则**：

   * 必须严格按照给定的分类规则进行判断。分类规则已明确列出，不允许超出这些规则进行推测或假设。

3. **输出多个候选类别的可能性**：

   * 鼓励输出多个可能的候选类别，特别是当光谱特征模糊或有多个重叠特征时。
   * 如果只能确定唯一的候选类别，请只输出一个。
   * 当出现较大不确定性时，必须注明并列出所有可能的候选类别。

4. **每个候选类别的简要解释**：

   * 对每个候选类别，输出简短且明确的解释（**不超过300字**）。解释应包括：

     * 与用户提供的描述相关的特征（如发射线特征、连续谱形态等）。
     * 判断该类别的依据。
   * **避免过于复杂的术语**，解释应简明易懂，适合初学者理解。

5. **避免输出不符合规则的类别**：

   * 只能输出**允许的类别**：QSO、ELG、LRG/BGS，共三种。**不允许**输出其他任何类型，即使在光谱特征上存在某些模糊性。

6. **对于无发射线或连续谱简单的情况，按形态判断**：

   * 如果光谱仅包含连续谱，且无明显的发射/吸收线，按照连续谱形态进行大概率判断（如连续谱单调递增/递减）。
   * 如果有其他模糊特征，也应优先根据形态进行判断。

7. **不确定性处理**：

   * 对于信噪比低、连续谱几乎平坦、或仅有吸收线等特殊情况，**必须输出多个候选类别**并注明不确定性。
   * 不确定时，提供合理的候选类别组合，并明确指出后续定量分析的重要性。

### 注意事项

* **连续谱单调性**：如果连续谱并非完全单调递增或递减，而又必须做一个大致判断时，请根据最蓝端(光谱波长最小处)和最红端(光谱波长最大处)的连续谱流量大小进行粗略比较。不能仅以连续谱形态作为决定性判据。
* **红移信息**：由于红移未知，相关数据都是观测系结果，无法确定对应的具体谱线，因此请根据已知信息进行大致分类，最终红移和谱线确认仍需定量分析，暂不在此讨论。
* **谱线信息**：受找峰程序影响，谱线的中心波长、幅度和宽度都可能存在偏移。同时为求简便，算法将 >2000 km/s 的谱线认证为宽线，<1000 km/s 的谱线认证为窄线，1000-2000 km/s 的谱线认证为中等宽度。因而中等宽度的谱线实际上是对宽线和窄线的过渡，具体分类时请根据实际情况判断如何将中等宽度的谱线进行归类。
* **对细节的灵活性**：尽管规则要求严格，但在遇到边界情况时，可以灵活判断，保持合理性。

### 格式要求

* **简洁明了**：每个候选类别的解释应尽量简洁，并准确表达出分类的依据。
* **避免多余内容**：每条输出应避免包含与任务无关的内容，按示例格式直接针对分类问题给出清晰答复。不允许输出推理过程。
* **至多输出 2 个候选类别**。

## 快速决策树

请按以下优先级从上到下依次检查，**命中即纳入候选**，同时继续向下检查（可同时命中多条）：

```
Q1：光谱中是否包含两个及以上幅值明显的吸收线，且连续谱符合典型的 LRG/BGS 特征（蓝低红高）？
│
├─ 是 → 优先考虑 LRG/BGS，宽线可能是伪峰。
│
└─ 否 ↓

Q2：光谱中是否存在宽发射线（宽度 > 2000 km/s，或 1000-2000 km/s 的中等宽度但更靠近宽线）？
│
├─ 是 → 优先考虑 QSO（典型 QSO，情况1）
│    ├ 蓝端上升 + 中后段下降 → 高红移 QSO（Lyα 可见）
│    └ 蓝端下降 + 红端上升 → 低红移 QSO（Mg II 可见，搭配窄线）
│
└─ 否 ↓

Q3：连续谱形态是否与发射线特征不匹配？（如：连续谱为 ELG或LRG/BGS 形态，但有幅值显著的宽线，或有且仅有一个宽线展宽内叠加吸收线的复杂结构）
│
├─ 是 → 优先考虑 QSO（宿主星系主导的AGN，情况2），同时也优先考虑 LRG/BGS
│
└─ 否 ↓

Q4：发射线是否以窄线为主（宽度 < 1000 km/s）？
│
├─ 是 → 优先考虑 ELG 或 LRG/BGS；存在大于两条吸收线时，优先考虑 LRG/BGS；吸收线较少，优先考虑 ELG
│
└─ 否 ↓

Q5：上述条件均无法明确判断？
│
├─ 是 → 输出多个候选，由后续定量分析判定
│    常见组合：QSO + ELG（连续谱递减但线宽不确定）
│                ELG + LRG/BGS（窄线主导）
```

**使用说明**：
- 决策树用于快速定位候选类别，最终判断仍需结合下方详细分类规则。
- 同一光谱可同时满足多条路径，此时输出多个候选。
- 如遇到边界 case（信噪比极低、连续谱几乎平坦、仅有吸收线），也请输出多个候选并注明不确定性。

## 分类规则
### 类别一：QSO (类星体)

类星体（QSO）通常展现出高度的谱线发射特征及特殊的光谱形态，通常表现为幅值显著的宽发射线、明显的蓝端上升或红端上升等特点。QSO的光谱分类可能涉及以下两种主要情况：

#### 1. 情况一：典型 QSO（典型类星体）

* **光谱形态**：典型 QSO 的连续谱通常在蓝端较高，红端较低，呈现单调下降趋势。但在某些情况下，连续谱可能表现为较为复杂的变化：

  * **最蓝端存在随波长变大而上升，最红端存在随波长变大而下降**：这是高红移 QSO 的典型特征，通常在 Lyα 及其森林区间出现。连续谱在蓝端上升的原因是 Lyα 谱线的蓝侧通量较低，波长过渡至 Lyα 后，连续谱会单调下降。这类 QSO 的发射线通常较宽，且 Lyα 谷的轮廓清晰。
  * **最蓝端存在随波长变大而下降，最红端存在随波长变大而上升**：这是低红移 QSO 的典型特征，通常表现为可见的 Mg II 发射线。低红移 QSO 的红端上升通常是由于高通量的窄线区域（如 O [III] 双线、O [II] 等）主导了红端光谱。此类 QSO 的红端会呈现窄线区，且常伴有窄线特征，尤其是在红移较低的 QSO 中。

* **发射线特征**：类星体通常表现为宽发射线（例如 Lyα、C IV、Mg II 等），但找峰算法中，发射线的宽度可以被判定为中等宽度

* **常见发射线**：

  * 高红移 QSO：Lyα（1216 Å）、C IV（1549 Å）、C III]（1909 Å）
  * 低红移 QSO：Mg II（2800 Å）、O [III]（4959 Å 和 5007 Å）、O [II]（3728.5 Å）

#### 2. 情况二：宿主星系主导的 AGN

* **光谱形态**：在这种情况下，QSO 的连续谱形态可能由宿主星系主导，且呈现类似 ELG、LRG 或 BGS 的光谱特征，尤其在连续谱的光度上。然而，尽管光谱外观可能接近其他类型的星系（如 ELG 或 LRG/BGS），QSO 依然显示出一些显著的、典型的 AGN 发射线特征。

* **发射线特征**：这种类型的 QSO 通常包含强烈的 AGN 特征发射线，如：

  * **Ne [V]**（3426 Å）
  * **O [III]**（4959 Å 和 5007 Å）
  * **C III]**（1909 Å）
  * **O [II]**（3727 Å）
  * 也有些具有宽发射线的特征（例如 Mg II 宽发射线叠加在宿主星系的 Mg II 窄吸收线中）。

* **谱线复杂性**：由于发射线宽度的变化和宿主星系光谱的影响，可能出现宽发射线和窄吸收线的叠加。特别是在红移后的 Mg II 区域，由于 AGN 宽线和宿主星系的 Mg II 窄吸收线叠加，可能会出现过拟合的情况，导致峰值识别程序误判，算法可能会**误识别为单一宽线上叠加一窄吸收线，或误识别为多个接近的宽线**。遇见相关特征时请必须考虑此类型的QSO。

* **注意事项**：

  * 由于峰/谷识别算法的限制，可能会出现误判，例如宽发射线叠加宿主星系吸收线的情况。需要特别小心这些特征，且后续的定量分析会帮助确认这些发射线的实际宽度和位置。
  * 这种类型的 QSO 通常表现出较强的 AGN 特征，但可能与其他类型的星系光谱相似，因而需要结合后续的定量分析进一步确认。


### 类别二：ELG（Emission Line Galaxy，发射线星系）
- 连续谱大多呈现单调递减的情况，这也导致从连续谱形态上难以与QSO分别。此外，连续谱也可能呈现单调递增，或先增后减、先减后增的变化。
- 主要特征是发射线由窄线主导（也可能显示中等宽度），常见 O [II]、O [III] 双线、Hα 等。需等待定量计算结果，在此阶段不做具体分析。基本不出现明显的宽线。
- 峰值检测的过拟合可能会给出假的宽线，一般异常矮、异常宽，与整体趋势不符。
- 最终判断出的红移较低。

### 类别三：LRG/BGS（Luminous Red Galaxy/Background Galaxies，亮红星系/背景星系）
LRG 和 BGS 光谱特征类似，通常具有单调递增的连续谱和窄发射线特征。它们常出现在中到低红移范围，并且通常关联于较为成熟的恒星形成活动。
#### 1. 连续谱形态
* **单调递增**：LRG 和 BGS 的连续谱大多单调递增，即随着波长的增加，光谱亮度逐渐变强。少数情况下，连续谱可能呈现递减或其他变化（如先增后减、先减后增）。
#### 2. 发射线特征
* **窄线主导**：LRG 和 BGS 的发射线通常是窄线，典型发射线包括 O [II]（3727 Å）、O [III]（4959 Å 和 5007 Å）以及 Hα（6563 Å）。发射线宽度一般小于 1000 km/s，但在某些情况下，可能被识别成中等宽度。
* **吸收线**：LRG 或 BGS 常常展示较多的吸收线。
#### 3. 光谱识别注意事项
* **发射线与吸收线的组合**：LRG 光谱中常见的吸收线，如 Na I D、Ca H/K 等，可以帮助区分它们与其他类型的星系。吸收线较多的情况下，优先考虑 LRG 分类。
* **峰/谷识别**：LRG 和 BGS 的光谱在峰/谷分析中可能显示较为平滑的特点，且一般不包含宽发射线或复杂的发射线结构。受找峰算法过拟合的影响，峰值检测可能会给出假的宽线，一般异常矮、异常宽，与整体趋势不符。这些假的宽线往往会跨过一条或几条吸收线，或处于两吸收线之间，使得谱线情况呈现较为复杂的状态。
