## Background：QSO 光谱分类信息

QSO 的光谱分类涉及以下两种主要情况：

### 情况一：典型 QSO（典型类星体）

* **光谱形态**：连续谱通常在蓝端较高，红端较低，呈现单调下降趋势。也可能表现为蓝端上升红端下降（高红移特征，Lyα 森林区间），或蓝端下降红端上升（低红移特征，窄线区主导红端）。
* **发射线特征**：通常表现为宽发射线（Lyα、C IV、C III]、Mg II 等），但找峰算法中可能被判定为中等宽度。
* **常见发射线**：
    - 高红移 QSO：Lyα（1216 Å）、C IV（1549 Å）、C III]（1909 Å）、Mg II（2800 Å）
    - 低红移 QSO：Mg II（2800 Å）、O [III]（4959 Å 和 5007 Å）、O [II]（3727 Å）

### 情况二：宿主星系主导的 AGN

* **光谱形态**：连续谱由宿主星系主导，外观可能接近 ELG、LRG 或 BGS。关键识别依据是 AGN 特征发射线的存在，而非连续谱形态。
* **发射线特征**：包含强烈的 AGN 特征发射线：
    - Ne [V]（3426 Å）— AGN 的强指示线
    - O [III]（4959 Å 和 5007 Å）— 常见窄线区双线
    - C III]（1909 Å）
    - O [II]（3727 Å）
    - Mg II（2800 Å）— 可能表现为宽发射线叠加在宿主星系的窄吸收线上
* **谱线复杂性**：宽发射线与窄吸收线叠加，尤其在 Mg II 区域宽发射线叠加在宿主星系的窄吸收线上，寻峰/寻谷算法可能识别为单一宽线上叠加一窄吸收线，或误识别为两个接近的宽线，或过拟合导致假的宽线。

## Rules

### R1: 典型 QSO 分析注意事项

1. **宽度尽量匹配**：宽发射线的宽度分类应尽可能与谱线物理期望一致。如 narrow 峰匹配 broad 线 Lyα/C IV/C III]/Mg II 等，会被标注 `⚠ width mismatch`，反之亦然。这是重要的物理依据。当然，宽度可能会受其他因素影响，如谱线重叠/相近、寻峰算法的局限性等，请根据实际情况灵活判断。
2. **幅值尽量匹配**：各个宽发射线的幅值(Amplitude)大小的相对关系应与谱线物理期望一致，如Lyα、C IV、C III]、Mg II 的幅值一般是递减的，Lyα、C IV等不可能明显地比 Mg II 幅值矮。幅度也可能会受其他因素影响，如寻峰算法的局限性等，请根据实际情况灵活判断。
3. **连续谱形态**：连续谱的形态应与 QSO 的典型形态一致，即
    - **单调下降**：典型 QSO 的连续谱形态。
    - **最蓝端存在随波长变大而上升，最红端存在随波长变大而下降**：这是高红移 QSO 的典型特征，通常在 Lyα 及其森林区间出现。连续谱在蓝端上升的原因是 Lyα 谱线的蓝侧通量较低，波长过渡至 Lyα 后，连续谱会单调下降。这类 QSO 的发射线通常较宽，且 Lyα 谷的轮廓清晰。
    - **最蓝端存在随波长变大而下降，最红端存在随波长变大而上升**：这是低红移 QSO 的典型特征，通常表现为可见的 Mg II 发射线。低红移 QSO 的红端上升通常是由于高通量的窄线区域（如 O [III] 双线、O [II] 等）主导了红端光谱。此类 QSO 的红端会呈现窄线区，且常伴有窄线特征，尤其是在红移较低的 QSO 中。

### R2: 宿主星系主导 AGN 分析注意事项

1. **连续谱不可靠**：不能以连续谱形态作为绝对判断依据，必须依赖 AGN 特征发射线。
2. **O [III] 双线是首选锚定特征**：双线结构（幅值比约 1:3，wavelength_1 < wavelength_2）是最可靠的红移锚定点。
3. **Ne [V] 是强 AGN 指示线**：非 AGN 天体几乎不出此线，匹配到该线时应高度重视 AGN 假设。
4. **可能存在强 Balmer 系线**（Hα/Hβ/Hγ/Hδ），需注意其对谱线匹配的潜在影响。
5. **Mg II 区域需审慎解读**：AGN 宽 Mg II + 宿主星系窄 Mg II 吸收的叠加可能导致过拟合，需特别注意误判。
6. **红移范围**：此类 QSO 红移通常在 0~1 之间；若结果特别靠近 0（如 0.01 量级），假设可能不成立。

### R3: 暴力匹配结果的使用注意事项

0. **理解暴力匹配结果**：暴力匹配结果列出了所有可能的谱线匹配组合，以及每种组合的匹配数和红移值。
1. **红移值的合理性**：情况一（典型 QSO）的红移一般大于1，情况二（宿主星系主导 AGN）的红移一般小于1。
2. **匹配数最多的假设未必正确**：匹配数仅反映统计上的可能性，物理合理性优先于匹配数量。需要注意：
    - 谱线组合是否自洽
    - 红移是否在天文合理范围内
    - 宽峰是否误被当作窄发射线处理？窄峰是否误被当作宽发射线（Lyα、C IV、C III]、Mg II 等）处理？
    - 幅值是否匹配？如 Lyα、C IV等不可能明显地比 Mg II 更矮。
3. **注意 Redshift warning**：若某假设的红移低于 MIN_QSO_REDSHIFT 或 MIN_GALAXY_REDSHIFT，该假设的物理合理性应被质疑。
4. **一对多归属是正常的**：同一观测峰可能同时匹配多条不同静止系谱线，需结合其他峰的匹配结果和物理约束择优。
5. **缺失匹配不等于不存在**：暴力匹配依赖容差窗口，物理上应存在的谱线可能未在匹配中出现。寻峰/寻谷算法也可能出现漏检或伪峰，需仔细甄别。

### R4 暴力匹配结果的内容说明

每个匹配结果包含以下字段：

1. **Hypothesis**：该假设中所有锚定匹配的列表，格式为"观测波长-谱线名"。锚定匹配是指以某个峰为某条发射线计算红移、再反推其他谱线位置而得到的完整匹配组。
2. **z_max / z_min / z_spread**：该假设下所有匹配对的红移最大值、最小值及差值（z_spread = z_max - z_min）。z_spread 的大小由匹配容差窗口（tol_wavelength）决定，**不代表假设的可信度高低**，请勿将其作为判据。所有数值保留 3 位小数。
3. **N_emission / N_absorption**：匹配到的**唯一谱线名**数量（非匹配对数）。同一谱线名被多个不同波长的峰匹配只计 1 次。
4. **Redshift warning**：若 z_max 低于配置的红移下限，会标注警告类型（"z too low for QSO" / "z too low for Galaxy"）。非空时需质疑该假设的物理合理性。
5. **Emission matches**：发射线匹配列表，每条格式为：
   `观测波长 Å (Amp=幅值, W=半宽Å/半宽 km/s, 宽度分类) → 谱线名 (z=红移)`
   - 括号内为寻峰结果的特征信息：幅值 (Amplitude)、半高全宽 (FWHM) 和宽度分类 (narrow / intermediate / broad)
   - 若宽度分类与谱线物理期望不一致（如 narrow 峰匹配 broad 线 Lyα/C IV/Mg II 等），会标注 `⚠ width mismatch`
   - Balmer 系（Hα/Hβ/Hγ/Hδ）在 QSO 和 Galaxy 中宽窄均可，不会触发 width mismatch
   - 若寻峰结果缺少某字段，括号内对应项省略
6. **Absorption matches**：吸收线匹配列表，格式同上但无宽度校验。吸收线匹配的波长来源为寻谷结果。
7. **Missing emission lines**：在该假设的红移范围（z_min ~ z_max）内，理论上观测波长应落在光谱范围内、但未被匹配到的发射线列表。每条格式为：
   - `谱线名 (静止波长 Å rest) → 低端–高端 Å obs [in range, not matched]`：z_min 和 z_max 两端算出的理论观测波长均在范围内，但未匹配。**这类线缺失需要重点关注**：可能是确实不存在、寻峰算法漏检、信噪比不足，或假设本身不成立。
   - `谱线名 (静止波长 Å rest) → ~估计波长 Å obs [possibly in range]`：仅红移一端的理论波长在范围内，提示参考。
   - 若列表为空（none），说明该假设的红移范围内所有在观测范围内的发射线均已匹配。
8. **发射线/吸收线匹配中可能会出现单一峰/谷匹配多条谱线，或多个峰/谷匹配同一条谱线的情况。**这是由于寻峰/寻谷算法的局限性（可能将一条宽谱线上的噪声或波动识别成多条谱线），以及谱线重叠/相近导致的。

## Steps

针对 user prompt 中给出的**当前单条假设**，依次完成以下步骤：

### Step F-1: 假设描述

1. 浏览当前假设，关注以下内容：
    - 匹配到的谱线数 N_emission 和 N_absorption 各有多少？
    - 是否标注了红移警告 Redshift warning？
    - 有哪些谱线匹配存在 width mismatch？
    - 存在 width mismatch 的匹配是否有替代物？例如：假设中同时存在
        - `wavelength_1 (..., intermediate) → Lyα (z=z_1)`
        - `wavelength_2 (..., narrow) → Lyα (z=z_2) ⚠ width mismatch`
        - `wavelength_3 (..., intermediate) → Lyα (z=z_3)`
        则 wavelength_2 → Lyα 虽有 width mismatch，但存在替代匹配，假设仍可能合理，极有可能是仪器效应或星系间介质吸收导致 Lyα 的展宽被吸收线分割，形成三峰的状态，真实的中心波长可能介于三者之间。反之对窄线亦然。
2. 当前假设更接近 QSO 的情况一（典型 QSO）还是情况二（宿主星系主导 AGN）？

### Step F-2: 物理验证

在 Step F-1 的基础上，进行物理语义验证：

1. 如果更接近情况一（典型 QSO）：
    - **Missing emission lines** 中是否提示了重要谱线（Lyα、C IV、C III]、Mg II）缺失？哪些缺失是可以接受的，哪些是致命的？
    - Lyα、C IV、C III]、Mg II 的幅值相对大小是否符合预期？（如 Lyα/C IV 幅值不应明显低于 Mg II）。
        - 一种特例是，某条谱线，以 C IV 为例，可能存在多个候选匹配，其中有的匹配幅值小于 Mg II，但有的匹配幅值高于 Mg II，如
            - `wavelength_1 (Amplitude=1.2,...) → C IV (z=...)`
            - `wavelength_2 (Amplitude=0.2,...) → C IV (z=...) `
            - `wavelength_3 (Amplitude=0.8,...) → C IV (z=...)`
            - `wavelength_4 (Amplitude=0.6,...) → Mg II (z=...)`
        wavelength_2 的幅值明显小于 wavelength_4 的 Mg II，但存在其他匹配 wavelength_1 和 wavelength_3符合条件，这是可以允许的，且说明 wavelength_1 和 wavelength_3 是 C IV 的更优匹配。
    - Width mismatch 是否有替代物？
2. 如果更接近情况二（宿主星系主导 AGN）：
    - 假设中是否存在 O [III] 双线？如果存在，双线波长比是否接近 Amplitude_a:Amplitude_b ≈ 1:3 (wavelength_a = 4960.3 Å, wavelength_b = 5008.2 Å) ，或者至少前者比后者略低？
    - 在光谱中，O [III] 双线往往会与 Hβ 重叠，对应的谱线匹配可能较复杂，请耐心梳理。例如：
        - `wavelength_1 (...) → Hβ (...)`
        - `wavelength_1 (...) → O [III]a (z=...) `
        - `wavelength_2 (...) → Hβ (z=...)`
        - `wavelength_2 (...) → O [III]a (z=...)`
        - `wavelength_2 (...) → O [III]b (z=...)`
        - `wavelength_3 (...) → O [III]a (z=...)`
        - `wavelength_3 (...) → O [III]b (z=...)`
        - `wavelength_1 < wavelength_2 < wavelength_3`
        此时易梳理出 wavelength_1 → Hβ，wavelength_2  → O [III]a，wavelength_3 → O [III]b。
    - 在 Mg II 区域，可能会出现宽发射线叠加在宿主星系的窄吸收线上，寻峰/寻谷算法可能识别为单一宽线上叠加一窄吸收线，或误识别为两个接近的宽线，或过拟合导致假的宽线。如果存在 Mg II，是否能与这些现象相符？
3. 综合考量：原寻峰/寻谷结果中 Amplitude rank 靠前的峰/谷，在当前假设中是否被合理解释？若有显著峰未被匹配，是否意味着假设不成立？

### Step F-3: 本条假设结论

对当前假设给出单条评估结论（不做跨假设比较，那是后续步骤的工作）：

1. **物理类型**：情况一（典型 QSO）/ 情况二（宿主星系主导 AGN）
2. **可信度**：high / medium / low，并说明主要理由（1-2 句）
3. **主要支持证据**：列出有力的支持点，不超过100字。
    - 尤其要具体说明该假设如何处理多个峰值匹配一条谱线的问题（如多个峰可能是同一个峰被切割/误识别为多个，或者某些峰是不显著的，可以忽略），或一个峰值匹配多条谱线的问题（比如如何成功理清谱线关系）。如对 Step F-1 的例子：
        - `wavelength_1 (..., intermediate) → Lyα (z=z_1)`
        - `wavelength_2 (..., narrow) → Lyα (z=z_2) ⚠ width mismatch`
        - `wavelength_3 (..., intermediate) → Lyα (z=z_3)`
    我们已论述这极有可能是仪器效应或星系间介质吸收导致 Lyα 的展宽被吸收线分割，形成三峰的状态，真实的中心波长可能介于三者之间。那么可以说：“wavelength_1、wavelength_2、wavelength_3 同时匹配 Lyα，但其中有两个中等宽度、一个窄谱线。三者判断出的红移接近，极有可能是仪器效应或星系间介质吸收导致 Lyα 的展宽被吸收线分割，实际谱线的中心波长可能在三者之间”。
    如果没有成功解决，则不能纳入此项。
4. **主要疑虑**：列出 1-2 条最关键的反对或存疑点
5. **建议红移**：若可信度不为 low，给出建议的红移值（取最低电离态谱线的 z）；若为 low 则填 N/A
6. **最终采纳配对**：基于 Step F-1/F-2 的推理，对每条已匹配的发射线给出最终采纳的观测波长及 z 值（有多候选时择优，无多候选时直接列出）。格式：
   - `谱线名 → 观测波长 Å (z=红移值)`
   - 未匹配的谱线不列出；吸收线不参与此项
