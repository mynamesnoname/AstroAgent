## Background：ELG 光谱分类信息

ELG（发射线星系）的光谱分类涉及以下两种主要情况：

### 典型 ELG（窄线主导发射线星系）

* **光谱形态**：连续谱形态多样，大多呈单调递减（蓝高红低），也可能单调递增或先增后减/先减后增。连续谱整体较为平坦，无明显的宽线隆起。
* **发射线特征**：发射线以**窄线**为主（宽度通常 < 1000 km/s，在找峰算法中通常为 narrow 或 intermediate 分类），幅值相对显著。**不出现真正的宽发射线**（如 Lyα/C IV/C III]/Mg II）；若出现标注 broad 的峰，需优先考虑是寻峰算法过拟合产生的伪峰（通常幅值异常低、宽度异常大，与整体趋势不符）。
* **常见发射线**：
    - O [II] 3727 Å（双线，但分辨率不足时可能呈单峰）
    - O [III] 4959 Å 和 5007 Å（双线，幅值比约 1:3，5007 Å 更亮。若两线幅值比与 1:3 相差较远，需考虑是否并非 O [III] 双线，可能为其他窄线如 Balmer 系或 N [II]/S [II] 等其他双线）
    - Hβ 4861 Å
    - Hα 6563 Å
    - Ne [III] 3869 Å
    - Hγ 4340 Å、Hδ 4102 Å（较弱，可能缺失）
* **注意**：部分 ELG 可能以其他窄发射线为主要可观测特征，O [II] 或 O [III] 可能因红移、信噪比或物理原因不显著，不因此排除 ELG。
* **红移范围**：通常 0 < z < 1.5。

### 误分类风险：宿主星系主导的 AGN （一种特殊的 QSO）
宿主星系主导的 AGN 可能被误分类为 ELG。

* **光谱形态**：连续谱外观类似 ELG，但可能同时含有 QSO 的宽发射线迹象（如宽 Mg II 叠加宿主星系窄吸收，或宽 Hα）。
* **发射线特征**：在典型 ELG 谱线（O [III]、O [II]、Hβ 等）之外，还出现 AGN 特征谱线：
    - Ne [V] 3426 Å（高电离线，ELG 中通常不出现）
    - C III] 1909 Å、C IV 1549 Å（若红移允许）
    - Mg II 2800 Å 宽线成分
* **谱线复杂性**：Mg II 区域可能出现宽线叠加窄吸收线，寻峰算法可能误识别为两个相邻的宽线或宽线上叠加窄吸收谷。遇到此类特征应考虑 AGN 成分的存在。

## Rules

### R1: 典型 ELG 分析注意事项

ELG 的发射线以窄线为主，预期宽度分类为 narrow 或 intermediate。若某峰匹配了 O [III]、O [II]、Hα 等窄线，但宽度类为 broad，将被标注 `⚠ width mismatch`，需重点关注。

1. **O [III] 双线是首选锚定特征**：双线结构（幅值比约 1:3，λ₁=4959.1 Å, λ₂=5006.8 Å，λ₁ 幅值低于 λ₂）是最可靠的红移锚定点。若双线均存在且幅值比合理（至少幅值的大小分配合理），可信度显著提升。**若两线幅值比与 1:3 相差较远，需考虑是否并非 O [III] 双线，可能为其他窄线（如 Balmer 系或 S [II] 双线）。**如果没有 O [III] 双线，需严格检查其他谱线的匹配是否合理。
2. **O [II] 3727 Å 是次优锚定特征**：O [II] 是 ELG 中最常见的发射线之一，低分辨率下呈单峰。若与 O [III] 红移吻合，可信度进一步提升。
3. **Hα/Hβ 提供额外验证**：Balmer 系谱线在 ELG 中为窄线，若与 O [III]、O [II] 的红移一致，可增强假设可信度。
4. **宽线 mismatch 是重要警示**：ELG 中出现多个宽线匹配（broad 分类且无 narrow/intermediate 替代），且幅值显著，应质疑该假设是否合理。
5. **红移范围**：此类 ELG 红移一般在 0 ~ 1.5；若结果特别靠近 0（如 0.001 量级），假设可能不成立。
6. **注意 Redshift warning**：若某假设的红移低于 MIN_GALAXY_REDSHIFT，该假设的物理合理性应被质疑。

### R2: 暴力匹配结果的使用注意事项

0. **理解暴力匹配结果**：暴力匹配结果列出了所有可能的谱线匹配组合，以及每种组合的匹配数和红移值。
1. **红移值的合理性**：红移一般在 0 ~ 1.5 之间。
2. **匹配数最多的假设未必正确**：匹配数仅反映统计上的可能性，物理合理性优先于匹配数量。需要注意：
    - 谱线组合是否自洽
    - 红移是否在天文合理范围内
    - 宽峰是否误被当作窄发射线处理？窄峰是否误被当作宽发射线处理？
    - 幅值是否匹配？如 O [III]、O [II]、Hα 等基本是光谱中较明显的发射线。
3. **注意 Redshift warning**：若某假设的红移低于 MIN_GALAXY_REDSHIFT，该假设的物理合理性应被质疑。
4. **一对多归属是正常的**：同一观测峰可能同时匹配多条不同静止系谱线，需结合其他峰的匹配结果和物理约束择优。
5. **缺失匹配不等于不存在**：暴力匹配依赖容差窗口，物理上应存在的谱线可能未在匹配中出现。寻峰/寻谷算法也可能出现漏检或伪峰，需仔细甄别。

### R3 暴力匹配结果的内容说明

每个匹配结果包含以下字段：

1. **Hypothesis**：该假设中所有锚定匹配的列表，格式为"观测波长-谱线名"。锚定匹配是指以某个峰为某条发射线计算红移、再反推其他谱线位置而得到的完整匹配组。
2. **z_max / z_min / z_spread**：该假设下所有匹配对的红移最大值、最小值及差值（z_spread = z_max - z_min）。z_spread 的大小由匹配容差窗口（tol_wavelength）决定，**不代表假设的可信度高低**，请勿将其作为判据。所有数值保留 3 位小数。
3. **N_emission / N_absorption**：匹配到的**唯一谱线名**数量（非匹配对数）。同一谱线名被多个不同波长的峰匹配只计 1 次。
4. **Redshift warning**：若 z_max 低于配置的红移下限，会标注警告类型（"z too low for QSO" / "z too low for Galaxy"）。非空时需质疑该假设的物理合理性。
5. **Emission matches**：发射线匹配列表，每条格式为：
   `观测波长 Å (Amp=幅值, W=半宽Å/半宽 km/s, 宽度分类) → 谱线名 (z=红移)`
   - 括号内为寻峰结果的特征信息：幅值 (Amplitude)、半高全宽 (FWHM) 和宽度分类 (narrow / intermediate / broad)
   - 若宽度分类与谱线物理期望不一致（如 narrow 峰匹配 broad 线 Lyα/C IV/Mg II 等），会标注 `⚠ width mismatch`
   - Balmer 系（Hα/Hβ/Hγ/Hδ）在 QSO 和 Galaxy 中宽窄均可，不会触发 width mismatch
   - 若寻峰结果缺少某字段，括号内对应项省略
6. **Absorption matches**：吸收线匹配列表，格式同上但无宽度校验。吸收线匹配的波长来源为寻谷结果。
7. **Missing emission lines**：在该假设的红移范围（z_min ~ z_max）内，理论上观测波长应落在光谱范围内、但未被匹配到的发射线列表。每条格式为：
   - `谱线名 (静止波长 Å rest) → 低端–高端 Å obs [in range, not matched]`：z_min 和 z_max 两端算出的理论观测波长均在范围内，但未匹配。**这类线缺失需要重点关注**：可能是确实不存在、寻峰算法漏检、信噪比不足，或假设本身不成立。
   - `谱线名 (静止波长 Å rest) → ~估计波长 Å obs [possibly in range]`：仅红移一端的理论波长在范围内，提示参考。
   - 若列表为空（none），说明该假设的红移范围内所有在观测范围内的发射线均已匹配。
8. **发射线/吸收线匹配中可能会出现单一峰/谷匹配多条谱线，或多个峰/谷匹配同一条谱线的情况。**这是由于寻峰/寻谷算法的局限性（可能将一条宽谱线上的噪声或波动识别成多条谱线），以及谱线重叠/相近导致的。

## 分析步骤

针对 user prompt 中给出的**当前单条假设**，依次完成以下步骤：

### Step F-1: 假设描述

1. 浏览当前假设，关注以下内容：
    - 匹配到的谱线数 N_emission 和 N_absorption 各有多少？
    - 是否标注了 Redshift warning？
    - 有哪些谱线匹配存在 width mismatch？
    - 存在 width mismatch 的匹配是否有 narrow 或 intermediate 的替代物？若有，则该 mismatch 匹配可以降权；若无，则需重点质疑。例如：假设中同时存在
        - `wavelength_1 (..., broad) → O [III]a (z=z_1) ⚠ width mismatch`
        - `wavelength_2 (..., narrow) → O [III]a (z=z_2)`
        - `wavelength_3 (..., intermediate) → O [III]a (z=z_3)`
        则 wavelength_1 → O [III]a 虽有 width mismatch，但存在 wavelength_2 和 wavelength_3 作为替代匹配，假设仍可能合理，极有可能是较宽的 Hβ 落在附近，且计算出的观测系波长在暴力匹配的容差范围之内。
    - 是否存在多个峰值匹配同一条窄线（如多个峰同时匹配 O [III] 5007 Å）？这可能说明其中某些峰是伪峰（过拟合），或附近的峰值较多（Hβ、O [III]a、O [III]b 都集中在此处），或算法将一个真实宽峰切割为了多个窄峰。
2. 当前假设更接近情况一（典型 ELG）还是情况二（宿主星系主导 AGN）？

### Step F-2: 物理验证

在 Step F-1 的基础上，进行物理语义验证：

1. 如果更接近情况一（典型 ELG）：
    - 在光谱中，**O [III] 双线往往会与 Hβ 重叠**，对应的谱线匹配可能较复杂，请耐心梳理。例如：
        - `wavelength_1 (...) → Hβ (...)`
        - `wavelength_1 (...) → O [III]a (z=...) `
        - `wavelength_2 (...) → Hβ (z=...)`
        - `wavelength_2 (...) → O [III]a (z=...)`
        - `wavelength_2 (...) → O [III]b (z=...)`
        - `wavelength_3 (...) → O [III]a (z=...)`
        - `wavelength_3 (...) → O [III]b (z=...)`
        - `wavelength_1 < wavelength_2 < wavelength_3`
        此时易梳理出 wavelength_1 → Hβ，wavelength_2  → O [III]a，wavelength_3 → O [III]b。
    - **O [III] 双线**：是否同时存在 4960.3 Å 和 5008.2 Å 对应的匹配？两者幅值比是否接近 1:3（5007 Å 更亮）？若不存在，其他窄线的匹配是否合理？
    - **O [II] 3727 Å**：是否在当前红移下出现匹配？幅值是否相对较高？
    - **Hβ 4861 Å / Hα 6563 Å**：若在光谱范围内，是否有对应匹配？幅值是否合理（Hα 通常强于 Hβ）？
    - **Missing emission lines** 中是否有重要窄线缺失（O [III] 双线、O [II]3727 等）？哪些缺失是可接受的（信噪比低、在光谱边缘、可能漏检、或物理上缺失不存在），哪些是致命的？
    - **width mismatch**：如果存在 broad 峰匹配窄线，是否有 narrow/intermediate 替代？
2. 如果更接近情况二（宿主星系主导 AGN）：
    - 是否出现 Ne [V] 3426 Å 或 C III] 1909 Å 等高电离线匹配？
    - Mg II 区域是否有宽线迹象（broad 峰，或宽线叠加窄吸收谷的特征）？
    - O [III] 双线是否存在？幅值比是否合理？
3. 综合考量：原寻峰/寻谷结果中 Amplitude rank 靠前的峰/谷，在当前假设中是否被合理解释？若有显著峰未被匹配，是否意味着假设不成立？还是有其他特殊原因？

4. **可观测窄线核验**：对照输入的 `Observable emission lines` 列表，逐条说明所有落在观测范围内的窄发射线（O [II]、Hβ、O [III]a、O [III]b、Hα 等）的匹配状态（已匹配 / 在范围但未匹配 / 不在范围）。不得省略任何已匹配的窄线。若判为情况二（AGN），还需额外说明 Ne [V]、Mg II、C III] 等 AGN 特征线的状态。
   **注意**：O [II] 或 O [III] 在范围内但 NOT matched，不直接否决假设。若其他窄线匹配良好、红移内部一致，氧线缺失可能由低 SNR、波长覆盖边缘或物理上氧线确实较弱导致。Key_lines_status 中应如实记录但不作为唯一淘汰依据。

### Step F-3: 本条假设结论

对当前假设给出单条评估结论（不做跨假设比较，那是后续步骤的工作）：

1. **物理类型**：情况一（典型 ELG）/ 情况二（宿主星系主导 AGN）
2. **可信度**：high / medium / low，并说明主要理由（1-2 句）
3. **主要支持证据**：列出有力的支持点，不超过 100 字。
    - 尤其要具体说明该假设如何处理多个峰匹配同一谱线的问题（如某个 broad 伪峰被合理排除，或 O [III] 双线同时匹配且幅值比合理），或一个峰匹配多条谱线的问题或一个峰值匹配多条谱线的问题（比如如何成功理清谱线关系）。如对 Step F-1 的例子：
        - `wavelength_1 (...) → Hβ (...)`
        - `wavelength_1 (...) → O [III]a (z=...) `
        - `wavelength_2 (...) → Hβ (z=...)`
        - `wavelength_2 (...) → O [III]a (z=...)`
        - `wavelength_2 (...) → O [III]b (z=...)`
        - `wavelength_3 (...) → O [III]a (z=...)`
        - `wavelength_3 (...) → O [III]b (z=...)`
        - `wavelength_1 < wavelength_2 < wavelength_3`
    我们已论述 wavelength_1 → Hβ，wavelength_2  → O [III]a，wavelength_3 → O [III]b，那么可以说：“wavelength_1 匹配 Hβ，wavelength_2 匹配 O [III]a，wavelength_3 匹配 O [III]b，此处的混乱是由于 Hβ 落在 O [III] 双线附近，且计算出的观测系波长在暴力匹配的容差范围之内。”
    - 如果没有成功解决，则不能纳入此项。
    - 当不存在 O [III] 双线的时候，其他窄线匹配是否合理？
4. **主要疑虑**：列出 1-2 条最关键的反对或存疑点
5. **建议红移**：从 Adopted_pairs 中选取最低电离态谱线的 z，保留 3 位小数。优先 O [II]，其次 O [III]，再次 Hα/Hβ。若 Adopted_pairs 为空，填 N/A
6. **最终采纳配对**：基于 Step F-1/F-2 的推理，对每条已匹配的发射线给出最终采纳的观测波长及 z 值（有多候选时择优，无多候选时直接列出）。格式：
   - `谱线名 → 观测波长 Å (z=红移值)`
   - 未匹配的谱线不列出；吸收线不参与此项
