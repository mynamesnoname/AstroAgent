## Background：LRG/BGS 光谱分类信息

LRG（亮红星系）和 BGS（亮星系样本）的光谱特征来自其以老年恒星为主的星族，两者谱线特征高度类似，因而在此处统一处理，不做分别。

### 典型 LRG/BGS

* **光谱形态**：连续谱大致整体呈红端偏高、蓝端较低的形态（老年星族的红化效应），但具体细节因个体而异，不能作为绝对判据。连续谱相对平滑，无明显由宽发射线隆起导致的连续谱单调性的频繁变化。
* **4000 Å break**：光谱 4000 Å 处可能存在显著断折。Dn4000 是 4000 Å break 的强度指标，数值越大越显著。另外也需结合 4000 Å 附近光谱的斜率进行分析。一般来说，在 4000 Å 两侧（< 3950 Å 和 > 4000 Å），连续谱较为平缓，斜率接近于 0；在 3950-4000 Å 处，连续谱斜率显著增大。
* **主要谱线特征**：
    - **广泛存在吸收线**。同时存在**一定的窄发射线**。
* **常见吸收线**：
    - Ca K 3934 Å 和 Ca H 3968 Å（钙双线，最为特征性，K 线通常略深于 H 线，波长差约 34 Å）
    - G-band 4300 Å（CH 分子吸收带，中等宽度）
    - Mg b 5175 Å（镁吸收带）
    - Na D 5893 Å（钠双线，通常表现为一个较宽的谷）
    - Hβ 4861 Å 吸收（巴尔末系，通常弱于 Ca 线）
    - Hγ 4340 Å、Hδ 4102 Å（更高阶巴尔末吸收，更弱）
* **常见发射线**：
    - O [II] 3727 Å（星形成区禁线）
    - Hε 3970 Å（Balmer 系）
    - Hδ 4102 Å（Balmer 系）
    - Hγ 4341 Å（Balmer 系）
    - Hβ 4863 Å（Balmer 系）
    - O [III]a 4960 Å（NLR 禁线双线之一，弱线）
    - O [III]b 5008 Å（NLR 禁线双线之一，强线，双线幅值比 O[III]a : O[III]b ≈ 1:3）
    - N [II]a 6549 Å（NLR 禁线）
    - Hα 6565 Å（Balmer 系，与 N [II] 常近邻）
    - N [II]b 6585 Å（NLR 禁线）
    - S [II]a 6718 Å（NLR 禁线）
    - S [II]b 6733 Å（NLR 禁线）
* **红移范围**：通常红移约在 0 ~ 1.5。若红移过于接近 0（如 0.001 量级），则假设可能失真。

## Rules

### R1: 典型 LRG/BGS 分析注意事项

1. **有较多吸收线特征**：典型的 LRG/BGS 光谱存在很优秀的吸收特征。尤其是金属线，如 Ca K 3934 Å 和 Ca H 3968 Å。相对地，发射线特征较为复杂。另外，寻峰程序可能会将两吸收线之间的连续谱部分误识别为宽发射线，导致宽发射线的匹配并不准确。**因而在暴力匹配时，算法对宽峰和宽发射线进行了屏蔽，只关心窄发射线和所有吸收线的匹配**。这是算法行为，在谱线匹配中缺失宽峰特征**不构成对 LRG/BGS 分析的歧视性判断**。
2. **发射线特征应与星系特征匹配**：存在一定的窄发射线特征，如 O [II] 3727 Å、Hε 3970 Å、Hδ 4102 Å、Hγ 4341 Å、Hβ 4863 Å、O [III]a 4960 Å、O [III]b 5008 Å、N [II]a 6549 Å、Hα 6565 Å、N [II]b 6585 Å、S [II]a 6718 Å、S [II]b 6733 Å。这些发射线的特征应与星系的特征匹配。
3. **连续谱形态**：连续谱大致整体呈红端偏高、蓝端较低的形态（老年星族的红化效应），整体单调递增，但具体细节因个体而异，不能作为绝对判据。
4. **4000 Å break**：光谱 4000 Å 处可能存在显著断折。这是密集的金属吸收线（如 Ca K 3934 Å 和 Ca H 3968 Å）导致的。 Dn4000 是 4000 Å break 的强度指标，数值越大越显著。另外也需结合 4000 Å 附近光谱的斜率进行分析。一般来说，在 4000 Å 两侧（< 3950 Å 和 > 4000 Å），连续谱较为平缓，斜率接近于 0；在 3950-4000 Å 处，连续谱斜率显著增大。
5. **红移范围**：通常红移约在 0 ~ 1.5。若红移过于接近 0（如 0.001 量级），则假设可能失真。

### R2: 暴力匹配结果的使用注意事项

0. **理解暴力匹配结果**：暴力匹配结果列出了所有可能的谱线匹配组合，以及每种组合的匹配数和红移值。
1. **红移值的合理性**：通常红移值应在 0 ~ 1.5 之间。若红移值过于接近 0（如 0.001 量级），则假设可能失真。
2. **匹配数最多的假设未必正确**：匹配数仅反映统计上的可能性，物理合理性优先于匹配数量。需要注意：
    - 谱线组合是否自洽
    - 红移是否在天文合理范围内
    - 幅值是否匹配？
3. **注意 Redshift warning**：若某假设的红移低于 MIN_QSO_REDSHIFT 或 MIN_GALAXY_REDSHIFT，该假设的物理合理性应被质疑。
4. **一对多归属是正常的**：同一观测峰/谷可能同时匹配多条不同静止系谱线，需结合其他峰的匹配结果和物理约束择优。
5. **缺失匹配不等于不存在**：暴力匹配依赖容差窗口，物理上应存在的谱线可能未在匹配中出现。寻峰/寻谷算法也可能出现漏检或伪峰，需仔细甄别。

### R3: 暴力匹配结果的内容说明

每个匹配结果包含以下字段：

1. **Hypothesis**：该假设中所有锚定匹配的列表，格式为"观测波长-谱线名"。锚定匹配是指以某个峰为某条发射线计算红移、再反推其他谱线位置而得到的完整匹配组。
2. **z_max / z_min / z_spread**：该假设下所有匹配对的红移最大值、最小值及差值（z_spread = z_max - z_min）。z_spread 的大小由匹配容差窗口（tol_wavelength）决定，**不代表假设的可信度高低**，请勿将其作为判据。所有数值保留 3 位小数。
3. **N_emission / N_absorption**：匹配到的**唯一谱线名**数量（非匹配对数）。同一谱线名被多个不同波长的峰匹配只计 1 次。
4. **Redshift warning**：若 z_max 低于配置的红移下限，会标注警告类型（"z too low for QSO" / "z too low for Galaxy"）。非空时需质疑该假设的物理合理性。
5. **Emission matches**：发射线匹配列表，每条格式为：
   `观测波长 Å (Amp=幅值, W=半宽Å/半宽 km/s, 宽度分类) → 谱线名 (z=红移)`
   - 括号内为寻峰结果的特征信息：幅值 (Amplitude)、半高全宽 (FWHM) 和宽度分类 (narrow / intermediate / broad)
   - 若宽度分类与谱线物理期望不一致（如 narrow 峰匹配 broad 线 Lyα/C IV/Mg II 等），会标注 `⚠ width mismatch`
   - Balmer 系（Hα/Hβ/Hγ/Hδ）在 QSO 和 Galaxy 中宽窄均可，不会触发 width mismatch
   - 若寻峰结果缺少某字段，括号内对应项省略
6. **Absorption matches**：吸收线匹配列表，格式同上但无宽度校验。吸收线匹配的波长来源为寻谷结果。
7. **Missing absorption lines**：在该假设的红移范围（z_min ~ z_max）内，理论上观测波长应落在光谱范围内、但未被匹配到的吸收线列表。每条格式为：
   - `谱线名 (静止波长 Å rest) → 低端–高端 Å obs [in range, not matched]`：z_min 和 z_max 两端算出的理论观测波长均在范围内，但未匹配。**这类线缺失需要重点关注**：可能是确实不存在、寻谷算法漏检、信噪比不足，或假设本身不成立。
   - `谱线名 (静止波长 Å rest) → ~估计波长 Å obs [possibly in range]`：仅红移一端的理论波长在范围内，提示参考。
   - 若列表为空（none），说明该假设的红移范围内所有在观测范围内的吸收线均已匹配。
8. **发射线/吸收线匹配中可能会出现单一峰/谷匹配多条谱线，或多个峰/谷匹配同一条谱线的情况。**这是由于寻峰/寻谷算法的局限性（可能将一条宽谱线上的噪声或波动识别成多条谱线），以及谱线重叠/相近导致的。
9. **Dn4000**：4000 Å break 的定量指标，分别以 z_max 和 z_min 当作真实红移计算。每组包含以下子字段：
   - `Dn4000`：mean_flux(4000–4100 Å) / mean_flux(3850–3950 Å) 的比值（静止系）；
   - `strength`：break 强度分级，`weak`（Dn4000 < 1.3）/ `moderate`（1.3 < Dn4000< 1.5）/ `strong`（Dn4000 > 1.5）/ `unphysical (Dn4000 < 1.0)`（物理上不合理，break 反向）/ `insufficient data`（对应窗口内数据点不足）；
   - `slope_3850_3950`、`slope_3950_4000`、`slope_4000_4100`：三个区间的线性斜率（单位：flux/Å，静止系）。
   
   **使用说明**：
   - z_max 和 z_min 对应两个略有差异的静止系映射，Dn4000 数值若在两组中一致，说明结论对红移误差不敏感；若差异较大，以更接近典型 LRG/BGS 特征的一组为准。
   - 典型 LRG/BGS 的 Dn4000 通常在 1.5–2.2 范围内（strong），Dn4000 < 1.3 对 LRG/BGS 假设是明显不利证据，需在 Step F-2 中说明。
   - `slope_3950_4000` 的绝对值通常显著大于 `slope_3850_3950` 和 `slope_4000_4100` 的绝对值，这是 4000 Å break 特征在斜率上的体现；若三段斜率无明显差异，则 break 特征弱。

## Steps

针对 user prompt 中给出的**当前单条假设**，依次完成以下步骤：

### Step F-1: 假设描述

1. 浏览当前假设，关注以下内容：
    - 匹配到的谱线数 N_emission 和 N_absorption 各有多少？
    - 是否标注了红移警告 Redshift warning？
    - 有哪些谱线匹配存在 width mismatch？
    - Absorption matches 中的谱线匹配是否合理？如果出现了 Ca K 和 Ca H 吸收线（这是 LRG/BGS 的有力判据），则很有可能能确证 LRG/BGS；但若未出现，依然需要考虑寻谷算法的局限性，尤其是出现强 4000 Å break，但未匹配到 Ca K 和 Ca H 吸收线的情况，更能证实是算法漏检对应的吸收线。

### Step F-2: 物理验证

在 Step F-1 的基础上，进行物理语义验证：

1. 如果可能是典型 LRG/BGS：
    - **吸收线验证**：吸收线是否合理？是否同时存在 Ca K（3934 Å）和 Ca H（3968 Å）对应的吸收谷匹配？
        - Ca K、Ca H 可能与其他谱线，如 Hε 混叠，对应的谱线匹配可能比较复杂，请耐心梳理。例如：
            - `wavelength_1 (...) → Ca K_abs (z=z_1a)`
            - `wavelength_1 (...) → Ca H_abs (z=z_1b)`
            - `wavelength_1 (...) → Hε_abs (z=z_1c)`
            - `wavelength_2 (...) → Ca K_abs (z=z_2a)`
            - `wavelength_2 (...) → Ca H_abs (z=z_2b)`
            - `wavelength_2 (...) → Hε_abs (z=z_2c)`
            - `wavelength_3 (...) → Ca H_abs (z=z_3a)`
            - `wavelength_3 (...) → Hε_abs (z=z_3b)`
            此时易梳理出 wavelength_1 → Ca K_abs，wavelength_2  → Ca H_abs，wavelength_3 → Hε_abs。
        - **若未匹配**，但存在 strong 或 moderate 的 4000 Å break，则 Ca K 和 Ca H 吸收线的缺失可能是算法漏检。
    - **其他吸收线交叉验证**：G-band_abs 4300 Å、Mg_abs 5175 Å、Na D_abs 5893 Å 在当前红移下是否出现对应匹配？哪些缺失是可接受的，哪些是不可接受的？
    - **4000 Å break 一致性**：是否有 4000 Å 附近的明显断折特征？

2. **综合考量**：原寻谷结果中 Amplitude rank 靠前的谷（吸收特征），在当前假设中是否被合理解释？若有显著谷未被匹配，是否意味着假设不成立？

3. **可观测吸收线核验**：对照输入的 `Observable absorption lines` 列表，逐条说明所有落在观测范围内的吸收线的匹配状态（已匹配 / 在范围但未匹配 / 不在范围），不得省略。**重要提示**：当前的寻峰/寻谷算法能力有限，Ca K（3935 Å）、Ca H（3970 Å）、G-band（4306 Å）等重要吸收线可能未被算法检出，因此 `Observable absorption lines` 中标注为 NOT matched 的吸收线不一定意味着假设不成立，需结合 4000 Å break 强度和其他吸收线的整体匹配情况综合判断。若存在 strong/moderate 的 4000 Å break 而 Ca K/Ca H 未匹配，很可能是算法漏检。

### Step F-3: 本条假设结论

对当前假设给出单条评估结论（不做跨假设比较，那是后续步骤的工作）：

1. **物理类型**：'典型 LRG/BGS' / '其他'
2. **可信度**：high / medium / low，并说明主要理由（1-2 句）
3. **主要支持证据**：列出有力的支持点，不超过 100 字。
    - 尤其要具体说明 Ca K/Ca H 双线是否成功匹配，以及多候选时如何选取最优配对。如果没有成功解决，则不能纳入此项。
    - 是否存在 strong 或 moderate 的 4000 Å break 的特征？
    - 如果存在 strong 或 moderate 的 4000 Å break 的特征，且其他吸收线匹配合理，则 Ca K 和 Ca H 吸收线的缺失可能是算法漏检。
4. **主要疑虑**：列出 1-2 条最关键的反对或存疑点
5. **建议红移**：若可信度不为 low，给出建议的红移值（优先取最低电离态谱线的 z）；若为 low 则填 N/A
6. **最终采纳配对**：基于 Step F-1/F-2 的推理，对每条已匹配的吸收线（及弱发射线）给出最终采纳的观测波长及 z 值（有多候选时择优，无多候选时直接列出）。格式：
   - `谱线名 → 观测波长 Å (z=红移值)`
   - 未匹配的谱线不列出
